AION2は**正式サービス開始時に基本プレイ無料**です。任意のメンバーシップ、プレミアム通貨、有料Battle Pass、Founder's Packがあります。先行アクセスと取引メンバーシップは用途が異なります。

<h2 id="free-and-paid">無料の部分と有料の部分</h2>

メンバーシップの**米ドル基準価格は月額15ドル**です。地域別の価格、通貨、税を含む最終金額は決済画面で確認できます。

| システム | 利用条件と特典 |
| --- | --- |
| 基本ゲーム | 基本プレイ無料 |
| メンバーシップ | 月額15米ドルが基準。MarketとKina–Quna Exchange、およびプレイ特典を利用できる |
| 通常Battle Pass | 全プレイヤーが利用可能 |
| プレミアムBattle Pass | Qunaで購入し、追加報酬を獲得 |
| ショップ外見 | 外見アイテムに戦闘ステータスはない |
| ショップ消耗品 | 一部はプレイを補助し、ゲーム内での入手手段もある |

無料で始め、プレイしてから利便性や成長特典の購入を決められます。**MarketとExchangeには有効なメンバーシップが必要です。** 購入前に最終金額を確認しましょう。

<h2 id="currency-and-trading">Kina・Quna・Market・Exchange</h2>

| 用語 | 用途 |
| --- | --- |
| Kina | ゲーム内で得る通貨。Marketの取引に使う |
| Quna | ショップとプレミアムパス用の通貨。Exchangeでも使う |
| Market | Kinaでアイテムを取引する。利用中のメンバーシップが必要 |
| Exchange | プレイヤー間でKinaとQunaを交換する。利用中のメンバーシップが必要 |

Exchangeは、一方がKina、もう一方がQunaを出すプレイヤー間取引です。交換で得たQunaもショップやプレミアムパスのQuna購入に使えます。

ExchangeやMarketを使う前に、メンバーシップ、現在の交換注文、アイテム価格を確認します。交換レートはプレイヤーの注文によって変わります。

<h2 id="quna-use-and-budget">Qunaの用途・入手方法・予算</h2>

**Qunaはプレミアム通貨**です。Quna価格のショップ商品、Battle Passのプレミアム枠、プレイヤーExchangeでKinaを買うために使います。Quna購入のほか、Exchangeで他プレイヤーにKinaを売って入手できます。**Exchangeには有効なメンバーシップが必要**です。直接のプレイヤー間アイテム取引は無効で、売買にはMarketを使います。

一般公開の基本ゲームへの入場に購入は不要です。予算は次のように分けてください。

- **入場：**正式サービスは無料。残りのAdvanced Access期間には対象パックが必要。
- **取引：**メンバーシップでMarketとExchangeが利用可能。米ドル基準は月15ドル。
- **Quna購入：**数量と現地通貨の最終価格を比較。プレイヤー間の交換率はQunaパックの現金価格とは別。
- **成長：**プレミアムパスには強化素材と通貨。外見アイテムには戦闘ステータスなし。

「勝つため」の想定額ではなく、欲しい商品や特典を決めて買いましょう。満員時には問題のないメンバーシップ利用者が優先待機列へ入りますが、即時ログインは保証されません。

<h2 id="founder-cosmetic-access">Founder外見と一度限りの報酬</h2>

Founder外見の変更では、対象外見を**全サーバーの全キャラクター**で使えるようになります。実装はまだ準備中で、Advanced Access終了後の予定です。新キャラクターで既に受け取れるとは考えないでください。

対象は購入した段階によって異なります。Standardの称号、Deluxeの防具・武器外見、Ultimateの追加防具外見・Black Dragonペット・Blazing Sunウイングです。**30日メンバーシップ、Supply Chest、Styling Chestと中身は一度限りの報酬のままです。**

上位パックへ変更したい場合、PURPLEではアップグレードが可能です。Steamは同じアカウントで上位を買い、下位の返金をサポートに依頼する案内ですが、詳細手順は準備中です。二重支払い前に[サポート](https://help.plaync.com/faq/aion2global)で手順を確認してください。

<h2 id="passes-and-progression">Battle Pass・外見・成長への影響</h2>

Battle Passは**キャラクター単位**で、無料枠とQunaのプレミアム枠があります。報酬は外見、強化素材、ゲーム内通貨です。購入前に対象キャラクターを決めてください。

ショップの外見アイテムには戦闘ステータスがありません。他の有料内容には素材、消耗品、取引機能、利便性の特典があるため、目的に合うものを選びましょう。

[ビルド](/builds)で必要な素材を確認しましょう。[Twitch Drops](/twitch-drops)と[クーポン](/code)でも報酬を受け取れます。

<h2 id="purchase-checklist">支払い前と購入失敗時の確認</h2>

1. ストア地域、通貨、最終金額を確認する。
2. 対象キャラクターがあるSteamまたはPURPLEアカウントを確認する。
3. 期間、付属メンバーシップ、キャラクター制限を読む。
4. パスでは対象キャラクターと現在の報酬枠を確認する。
5. ExchangeやMarketの利用計画では、メンバーシップと現在の注文を確認する。
6. 購入や配信が失敗したら領収書と正確なエラーを残す。

再起動で一部の購入・先行アクセス認識エラーの修正を適用します。続く場合はプラットフォーム、領収書、エラーを添えて[サポート](https://help.plaync.com/faq/aion2global)に連絡してください。
