<h2 id="find-presets">公式スタイルショップでプリセットを探す</h2>

[AION 2公式スタイルショップ](https://aion2.plaync.com/en-us/styleshop/popular)で共有外見を探しましょう。地域と期間を選び、**Most Downloaded**または**Most Liked**で並べ替えます。顔、髪、全身のプレビューを比較してから選んでください。

スタイルショップの共有外見を使う方法と、公開されたスライダーを手入力する方法があります。スタイルショップでは選択したキャラクターへダウンロードを送り、手入力では編集画面で設定を再現します。

気に入った外見の掲載ページを保存しておくと、後で見つけやすくなります。キャラクターへの送信は**Download**で行います。プレビューの閲覧は無料です。

<h2 id="download-apply">共有外見をダウンロードして適用する</h2>

<GuideVisual id="workflow" />

1. 実際に遊んでいるSteamやPURPLEなどの認証方法で公式サイトにログインする。
2. プロフィールの**Change Character**で、受け取るキャラクターを選ぶ。
3. **Style Shop**で外見を選び、**Download**を押して、現在のWebで使える枠を選ぶ。
4. 同じキャラクターでゲームを開き、**Customizations → Manage Appearance**へ進む。
5. すぐ表示されない場合は**Refresh**を使い、取得した外見を選んでプレビューする。
6. 適用前に確認画面を読む。現在のQuna料金や対象の外見変更券を確認し、表示条件に納得した場合だけ進める。

**ダウンロードと適用は別の操作です。** 取得した外見をプレビューし、Quna料金や対象の変更券を確認してから変更を確定しましょう。通貨の計画は[課金システム](/monetization)を参照してください。

<h2 id="upload-style">自分の外見を共有する</h2>

1. 共有したい外見のキャラクターで**Snapshot**を開く。
2. 照明をそろえ、メイン画像と顔・髪・全身の追加画像を撮る。
3. 保存した画像を探す。Steamでは`AppData\Local\AION2\Saved_Steam\Screenshots`を確認する。PURPLEでは専用のスクリーンショットフォルダーを使う。
4. Webで**同じキャラクター**を選ぶ。
5. **My Style → Register My Style**で必要な画像をアップロードし、登録画面を完了する。

スタイルショップの登録条件と[コンテンツ規定](https://aion2.plaync.com/en-us/board/rules/view?articleId=6aac4c8fab04307987fe2b4c)に従ってください。自分の作品を共有し、他人の外見を配布する場合は許可を得ましょう。

<h2 id="manual-sliders">手入力のプリセットを使う</h2>

手入力プリセットでは、スライダー画像や設定値を編集画面の横に用意します。細部を入力する前に、初期テンプレートを合わせましょう。

- 細部の入力前にテンプレート、顔、髪の選択肢を合わせる。
- 顔の形、目、鼻、口、髪、メイク、体を順番に調整する。初期形が違うと結果も変わる。
- 値や色が示されていれば使う。二次元スライダーの位置を目測する場合は近似になる。
- 複数の照明で正面、側面、斜めを比較してから確定する。

確定前に[キャラクター作成のチェックリスト](/character-creation)で比率、角度、照明を確認しましょう。

<h2 id="preset-troubleshooting">表示されない・合わない外見を確認する</h2>

| 問題 | 確認すること |
| --- | --- |
| ゲーム内にダウンロードがない | Webのログイン方法、キャラクター、地域、Manage Appearance → Refresh |
| Webで別キャラクターが出る | ログアウトして実際のプレイ用プラットフォームを選ぶ。同じメールでも同じゲームアカウントとは限らない |
| プレビューが違って見える | 初期形、カメラ角度、光、髪色、服装を複数の視点で比較する |
| KR/TWの外見リンクがある | Globalの掲載ページを探すか、作者の手入力設定を使う |
| 新規キャラクターにプリセットを使いたい | 作成画面で使えるプリセットと編集機能を使う |

作者のページと手入力設定を残しておくと後で確認できます。アカウントの問題は[公式サポート](https://help.plaync.com/faq/aion2global)に従い、同期確認のためだけに有料変更を何度も繰り返さないようにしましょう。

**Refresh後も表示されない場合：** サイトで選択したキャラクターとサーバーを、現在ゲームで開いているキャラクターと照合し、プラットフォームのログインと地域を確認します。再び適用を試す前に、サイトに戻って目的のダウンロード枠を確認してください。外観のリンク、受取キャラクター、操作時刻をサポート用に控えます。プレビューが見つからないからといって、二度目の有料外観変更を確定しないでください。
