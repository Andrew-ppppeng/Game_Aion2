<h2 id="official-downloads">Global版の公式ダウンロード先を選ぶ</h2>

AION2 GlobalのPC版は[Steam](https://store.steampowered.com/app/3393110/AION_2/)または[PURPLE](https://purple.plaync.com/download)から入手できます。Steamでは**AION 2、App 3393110**を選んでください。

先行アクセスには対象のFounder's Packが必要です。2026年10月5日の一般公開では基本プレイ無料なので、先行利用権を買わずにクライアントを準備できます。購入前に[Steamと開始日程](/steam)、[課金システム](/monetization)を確認しましょう。

<h2 id="pc-requirements">まずPC環境と空き容量を確認する</h2>

**Global PC版の必要環境：** Globalの公式サポートはWindows PC版です。この表はそのクライアント用で、KR/TWのモバイル環境は別の地域クライアント用です。端末選びの前に[対応プラットフォーム](/steam#platform-and-controller-support)を確認しましょう。

| 項目 | 最低 | 推奨 |
| --- | --- | --- |
| OS | Windows 10/11、64-bit | Windows 10/11、64-bit |
| CPU | Ryzen 5 2600 / Core i5-10500 | Ryzen 7 3700X / Core i7-11700 |
| メモリ | 8 GB RAM | 16 GB RAM |
| GPU | GTX 1050 Ti、4 GB | RTX 2070、8 GB |
| DirectX | 12 | 12 |
| 必要な空き容量 | 100 GB | 100 GB |
| 回線とドライブ | ブロードバンド、SSD推奨 | ブロードバンド、SSD推奨 |
| FHD設定 | Very Low | Low |

**100 GBの空き容量**を確保し、導入前にランチャーの容量表示も確認しましょう。ダウンロード量と後日のパッチ容量は異なります。FHDの最低環境はVery Low、推奨環境はLow設定です。

**空き容量で止まる場合：** インストール先のドライブの容量を空け、インストーラーの必要条件を満たしてから再開します。

<h2 id="check-your-specs">自分のPCスペックを確認する</h2>

1. **Windows + R**を押し、`dxdiag`を入力してDirectX診断ツールを開きます。
2. **System**でOS、CPU、メモリ、DirectXの版を確認し、上の表と比較します。
3. **Display**でGPU名を確認します。複数のGPUがあるPCでは、ほかのDisplayやRenderタブも確認しましょう。
4. SteamかPURPLEで選ぶドライブの空き容量を確認します。100 GBは必要な空き容量で、固定のダウンロード量ではありません。

表の最低環境では**FHD・Very Low**、推奨環境では**FHD・Low**から始めます。一定のフレームレートを保証する設定ではありません。

**スマートフォンにも入れられる？** ここではGlobalのWindows PC版を導入します。KR/TWのモバイルダウンロードやスマートフォンの環境をGlobalインストーラーの代わりに使わないでください。

<h2 id="steam-installation">Steamでインストールする</h2>

**Steamアカウント：** Steamで遊ぶためにPURPLEアカウントを連携する必要はありません。両方のランチャーで同じキャラクターと進行を使いたい場合に連携します。Globalの内容とサーバーは共通です。

1. 実際にプレイするSteamアカウントでログインします。
2. [AION 2の公式ストアページ](https://store.steampowered.com/app/3393110/AION_2/)を開き、アカウントで利用可能になった本編を追加・インストールします。
3. 十分な空き容量のあるドライブを選びます。SSDが推奨されます。ダウンロードと更新が完了するまで待ちましょう。
4. ライブラリから本編を起動し、そのクライアントに表示されるアカウント案内に従います。
5. キャラクター作成前に、友人と[地域・種族・サーバー](/server)を決めておきます。

テストに参加していた場合も、Globalで遊ぶにはライブラリの本編**AION 2、App 3393110**を導入します。Playtestは別のアプリです。

**Steamでファイル不足や破損が表示される場合：** ライブラリのAION 2で**Properties → Installed Files → Verify integrity of game files**を選び、完了後に再起動します。

<h2 id="purple-installation">PURPLEでインストールする</h2>

1. [PURPLEの公式ダウンロードページ](https://purple.plaync.com/download)からランチャーを入手します。
2. インストールして起動し、プレイするアカウントでログインします。
3. AION2のGlobalサービスを選び、保存先を指定してランチャーに表示されるダウンロード・更新を完了します。
4. 更新後にPURPLEからゲームを起動します。再インストールの前に、資格やメンテナンスの表示を確認しましょう。

**インドネシア、マレーシア、フィリピン、シンガポール、タイ**でPURPLEにAION2が出ない場合は、**ランチャーの地域をGlobal**にし、ゲーム一覧を確認して必要なら再起動します。アカウントの国は変更しません。

<h2 id="taiwan-client">別サービスの台湾クライアントを導入する</h2>

**TW/KRの進行はGlobalに移りません。** キャラクター作成前に遊ぶサービスを選びましょう。

**TW：** [台湾の公式ダウンロードページ](https://tw.ncsoft.com/aion2/download/index)を使います。別の地域サービスを導入する手順で、GlobalのSteamアプリは台湾サーバー用のインストーラーではありません。

1. 台湾のページから**PurpleInstaller**をダウンロードして導入します。
2. PURPLEを起動し、**STORE**で**AION2**を選びます。
3. ゲームロビーで**安裝遊戲**（ゲームをインストール）を選び、ダウンロードと更新を終えます。

**TWアカウント：** 自分のアカウントでログインし、台湾サービスで必要なアカウント確認を完了します。登録情報は本人確認書類と一致し、本人確認ができる内容である必要があります。導入だけでは地域の利用条件を満たしたことにはなりません。アカウント認証や地域制限で利用できない場合は、[台湾AION 2サポート](https://help.plaync.com/faq/aion2_tw)へ問い合わせてください。

<h2 id="launch-troubleshooting">ダウンロード後に起動できない場合</h2>

| 状況 | 最初に確認すること | 次の操作 |
| --- | --- | --- |
| 資格・利用権のエラー | 先行アクセス資格とログイン中のアカウント | 再起動・更新し、そのアカウントが利用権を持つか確認する |
| PURPLEにゲームがない | ランチャーの地域と上の対象国一覧 | Globalに設定してPURPLEを再起動する |
| サービスが利用できない | 最新の[メンテナンス告知](/maintenance) | 何度も再インストールせず、告知の終了を待つ |
| Steamが破損・欠落ファイルを報告 | ライブラリの本編項目 | ライブラリ→プロパティ→インストール済みファイル→ゲームファイルの整合性を確認する |
| インストールが終わらない | 選択したドライブの空き容量 | インストーラーの容量条件を満たして再開する |

改善しなければエラー、ランチャー、地域、発生時刻を記録し、[AION2サポート](https://help.plaync.com/faq/aion2global)に相談してください。
