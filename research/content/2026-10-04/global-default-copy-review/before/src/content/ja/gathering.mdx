<h2 id="start-gathering">Globalで採集を始める</h2>

Globalでは序盤の育成中から採集できます。近くの採集地点で必要条件を読み、利用できる地点から始めましょう。レシピや強化に必要な素材を選ぶと、最初のルートが育成に役立ちます。

**KR：** 不正プログラム対策として、採集の開放レベルがキャラクター45に引き上げられました。Globalの序盤の採集とは別の地域ルールです。

利用できる地点で一度採集し、得た素材と熟練度を確認してから、専門化ポイントの使用や長いルートを計画しましょう。

<h2 id="experience-specialization">採集経験値・専門化・製作を分けて考える</h2>

採集では**Success**と**Failure**のゲージが競合します。熟練度は**Essence Extraction**で確認してください。**Item Extraction**は装備を分解する別メニューです。採集熟練度と製作分野のレベルも別の条件です。

| システム | クライアントで確認すること |
| --- | --- |
| 採集経験値・熟練度 | 別の資源と同じ表示ゲージが進むか |
| 一般的な採集スキル | 成功率、速度、その他の採集コストに何が影響するか |
| 資源別の専門化 | 対象素材の地点表示、収量、品質に何が影響するか |
| 製作分野 | どのレシピが素材を使い、どんな製作条件があるか |

ポイントを使う前に、採集スキルの効果と対象素材を読みましょう。繰り返すルートに役立つスキルを優先します。

<h2 id="choose-materials">実際の目的に合わせて素材とスキルを選ぶ</h2>

<GuideVisual id="workflow" />

1. 完成させたいレシピや強化画面を開き、不足素材の名前と数量を記録する。
2. 現在の地域のマップで素材を探し、自分が採集できるか確認する。
3. 関連するスキルの説明を読む。不要な資源向けの強化より、繰り返し使える改善を優先する。
4. 短い試行で収量、失敗、移動時間を比較する。
5. 製作目標の変更や新しい資源段階の開放後に見直す。

<h2 id="gathering-routes">採集地点を探して短いルートを作る</h2>

[Aion2T](https://aion2t.com/map)で地域を選び、資源マーカーを絞り込めます。高い足場や洞窟は[Aion2Maps](https://www.aion2maps.com)で高さと接近経路を確認しましょう。マーカーは出現候補を示すため、到着時には資源がない場合もあります。

最初は、知っている目印の近くにある小さな集まりを回りましょう。

- 種族、エリア、開始地点を記録し、同じ試行を繰り返せるようにする。
- 素材を1つに絞り、無関係な表示を消して地形を確認する。
- 操作前に地点の必要条件を読む。
- 最初は消えている地点や通れない地点を飛ばす。固定の再出現時間を仮定しない。
- 決めた時間で試行を終え、操作回数ではなく役立つ素材の数を数える。

何も見えない地点や高さ違いは[マップガイド](/map)で確認してください。敵種族の地域を通るルートでは、[裂隙とPvPの危険](/spacetime-rift)も考慮しましょう。

<GuideVisual id="topic" />

**10分間のルートを比較する：** 必要な素材を一つ、近くの到達できる地点を三つ選びます。既知の目印から始め、成功と収量を記録し、10分後に合計します。繰り返すかどうかは移動時間も含めて判断しましょう。

<h2 id="route-results">採集ルートがうまくいかない理由を確認する</h2>

資源マップは**探す場所**を示し、採集地点の説明とEssence Extractionの進捗が**採れるもの**を決めます。[採集マップの絞り込み](/map#gathering-map-filters)で小さな集まりを探してから、ゲーム内で試しましょう。

| 結果 | 次の行動 |
| --- | --- |
| 資源は見えるが採集できない | 正確な条件を読み、現在の熟練度と比較する |
| 失敗が続く | 地点の難度と成功率関連スキルを確認してからルートを伸ばす |
| クエストの素材と違うものが採れた | 完全な名前・品質・**Bound**を確認し、似た素材を代用品として買わない |
| 移動に時間がかかりすぎる | 地点を減らし、繰り返す登りや大きな迂回を外す |
| 熟練度が増えなくなった | さらに採る前に段階上限と昇格クエストを確認する |

**必要な素材／役立つ個数／時間／失敗数**だけを記録します。取り組んでいるレシピや昇格に役立つルートを繰り返してください。適したルートは種族、到達可能な地点、熟練度で変わります。遠い高級素材は初心者向きとは限りません。

<h2 id="promotion-and-value">昇格条件と、採集するか買うかの判断</h2>

**Global・魔族：** **Novice 50**で昇格クエストに従い、**Safe HavenのAlzirr**を訪れます。必要な**Splendent Ruby (Bound)**は**Calderon Canyon**のRubyノードから入手します。製作素材の**Radiant Ruby Gemstone**とは別のクエストアイテムです。似た名前の宝石を買う前に、正確な指定品を確認してください。

| 状況 | 対応 |
| --- | --- |
| 経験値が増えない | 現段階の上限や昇格クエストを確認する |
| 失敗が多い | 熟練度と必要条件を比較し、成功率に関するスキルを調べる |
| 少量がすぐ必要 | その量の実際の購入価格と採集時間を比較する |
| 何度も使う素材が必要 | 再現できるルートを作り、役立つスキルだけに投資する |

一度に必要な量の購入価格と採集時間を比較しましょう。繰り返し使うレシピには短いルートが役立ちます。用途のわからない製作素材は保管し、バッグ整理の優先順位は[初心者ガイド](/guide)を参照してください。
