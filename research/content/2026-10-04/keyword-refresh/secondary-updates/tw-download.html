PURPLE電腦版安裝FAQ

PURPLE電腦版安裝FAQ

  1. 1. 於下載頁面中點擊[下載]按鈕進行PURPLE電腦版下載

  2. 2. 完成下載後，請於瀏覽器的下載資料夾中安裝PurpleInstaller

  3. 3. PURPLE電腦版安裝完成後，請執行並選擇STORE選單內的AION2

  4. 4. 於AION2大廳中點選[安裝遊戲]按鈕

客戶端說明

  • AION2

    • 容量 : 最初安裝時約需要70GB以上的容量
    • 功能 : 使用AION2遊戲
    • 移除方法 : 控制台>解除安裝程式>AION2
    • 對其他程式的影響 : 無
    • 作業系統 : Windows 10以上

  • PURPLE Windows

    • 容量 : 安裝前約399MB, 安裝後約1.52GB
    • 功能 : 安裝及執行遊戲
    • 移除方法 : 控制台 > 解除安裝程式 > PURPLE
    • 對其他程式的影響 : 無
    • 作業系統 : Windows 8.1以上
