# 反馈入口完整性修正

日期：2026-10-04。范围：四语 terms-of-service、privacy-policy 及全站页脚关联入口。

## 问题与原因

原实现依赖可选 NEXT_PUBLIC_FEEDBACK_URL。缺失时仍展示纠错区、复制模板及页脚入口，并向玩家输出未配置提示。原验收检查了页面状态和模板复制，却没有要求真实收件目的地，因此遗漏了操作路径不完整的问题。

## 最终处理

- 用户明确指定真实反馈邮箱 feedback@aion2wiki.space，要求保留原有反馈功能。
- 邮箱统一配置在 src/lib/site.ts，四语政策页显示该邮箱及 mailto:feedback@aion2wiki.space 邮件链接。
- 删除四语未配置文案及可选环境变量解析，保留纠错模板、复制功能、原页脚入口和标题锚点。
- 撤回本轮最初增加的未配置时隐藏功能逻辑及新帮助模块；最终实现没有新增反馈显隐流程。
- README 与 .env.example 同步说明真实邮箱的配置位置。
- AGENTS.md 补充公开页面完整性规则：审查政策页与关联入口，核对真实目的地及实际操作，不能用复制成功或 HTTP 200 代替功能完整性。

## 验收

- ESLint：修改的展示组件与站点配置通过。
- 生产构建 .qa/feedback-ready-build：148 个静态页面生成成功，TypeScript 通过。
- test:site-info：8 个四语站务页通过，包含准确邮件 href、可见邮箱、无未配置占位提示、模板复制、分析退出及 320/390px 布局。
- test:smoke：144 项页面检查、124 篇攻略及 132 项 sitemap 通过；所有站务页验证唯一真实联系链接。
- test:review 相关断言已同步修改并完成语法检查；本轮未重复运行整套浏览器审查。
- 独立只读复查了线上 50 个路由：已知反馈问题同样影响四语隐私页，未发现其他实际公开的 Coming soon 页面、空 href、裸 # 或虚假工具操作。

修改前的当前工作区副本保存在 before/，没有覆盖前次内容审查记录。本轮未发送测试邮件，也没有验证邮箱后台的收件配置；邮件链接的渲染与目的地址已验证。尚未部署，线上页面需随本轮修改发布后更新。
