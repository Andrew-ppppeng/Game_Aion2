<h2 id="official-downloads">Choose an official Global download</h2>

Download the Global PC version through [Steam](https://store.steampowered.com/app/3393110/AION_2/) or [PURPLE](https://purple.plaync.com/download). The official website's Download menu links to these two platforms. On Steam, check that the main game is **AION 2, App 3393110** before installing. [NC's launch announcement](https://about.ncsoft.com/news/article/A2_update_20261001) confirms both platforms and the planned October 5, 2026 public launch.

As of October 2, Global is in Advance Access for eligible players. Installing the client and holding access are separate steps: a completed download does not grant early entry. If you intend to play free at the public launch, you can prepare the client without buying access. See [Steam and launch information](/steam) and [monetization](/monetization) before choosing a package.

Older KR/TW tutorials may cover a mobile client, phone verification or different regional folders. Follow the Global PC installation below rather than mixing those instructions into your setup.

<h2 id="pc-requirements">Check your PC and storage first</h2>

These requirements come from the [official Steam product data](https://store.steampowered.com/api/appdetails?appids=3393110&cc=us&l=english), checked October 2, 2026.

| Component | Minimum | Recommended |
| --- | --- | --- |
| Operating system | Windows 10/11, 64-bit | Windows 10/11, 64-bit |
| Processor | Ryzen 5 2600 / Core i5-10500 | Ryzen 7 3700X / Core i7-11700 |
| Memory | 8 GB RAM | 16 GB RAM |
| Graphics | GTX 1050 Ti, 4 GB | RTX 2070, 8 GB |
| DirectX | 12 | 12 |
| Available storage | 100 GB | 100 GB |
| Connection and drive | Broadband; SSD recommended | Broadband; SSD recommended |
| Official FHD preset note | Very Low | Low |

**100 GB is required available disk space, not a fixed download size.** The compressed transfer and later patches can differ. Check the launcher's current space estimate before confirming the installation. The recommended specification's own note says FHD Low; it does not promise maximum settings or a particular frame rate.

**If installation stops for space:** inspect the drive you actually selected, not a different disk with more free space. Read the current installer message and resume after meeting that requirement. The published 100 GB is required available storage; a video showing a smaller transfer does not override the installation check.

<h2 id="steam-installation">Install through Steam</h2>

1. Sign in to the Steam account you actually intend to play on.
2. Open the [official AION 2 store page](https://store.steampowered.com/app/3393110/AION_2/) and add/install the main game when available to your account.
3. Choose a drive with sufficient free space, preferably an SSD. Let Steam finish downloading and applying updates.
4. Launch the main game from your Library and follow the account prompts presented by that client.
5. Before creating a character, agree on your [region, faction and server](/server) with friends.

If you previously joined a launch test, confirm that your Library entry is the released main game rather than a test entry. Do not assume that installing a test build gives you the current client or preserves its test character. The community's [archived Launch Scale Test FAQ](https://discord.com/channels/1113589630122606594/1113589937682526321/1549515406614601739) distinguishes the Steam main-game installation from the test.

**Worked Steam case: the main game is installed, but reports missing files.** Check that you opened **AION 2, App 3393110**, then use **Properties → Installed Files → Verify integrity of game files** and let the process finish before retrying. If the next attempt instead shows an access or maintenance message, move to that message's remedy. File verification does not grant Advance Access or make an unavailable service open.

<h2 id="purple-installation">Install through PURPLE</h2>

1. Get the launcher from the [official PURPLE download page](https://purple.plaync.com/download).
2. Install and open PURPLE, then sign in with your intended playing account.
3. Select the Global AION 2 service, choose its installation location and complete the download/update shown by the launcher.
4. Start the game from PURPLE after updating. Read any access or maintenance message before reinstalling anything.

For players in **Indonesia, Malaysia, the Philippines, Singapore and Thailand**, NC published a specific fix for AION 2 not appearing: set the PURPLE launcher region to **Global**, check the game list and restart PURPLE if needed. This is a launcher setting instruction for the countries listed in the [official region-settings notice](https://aion2.plaync.com/en-us/board/notice/view?articleId=6abd3200a279104f7d9d5eeb), not an instruction to change your account country.

**Worked PURPLE case for the published country list:** if a player in **Singapore** cannot see AION 2, the cited official notice tells them to set the **launcher region to Global**, inspect the game list and restart PURPLE if necessary. Apply this as the published launcher fix for a listed country; changing an account country or choosing a KR/TW service is a different action.

<h2 id="launch-troubleshooting">If the download finishes but the game will not start</h2>

| What you see | First check | Next action |
| --- | --- | --- |
| Access or eligibility message | Current Advance Access eligibility and your signed-in account | Read the [official account-fix update](https://aion2.plaync.com/en-us/board/notice/view?articleId=6abe2cf8a7ca1a15cf46bcbe); restart and update the client |
| Game missing from PURPLE | Global launcher region and the country-specific notice above | Restart PURPLE after applying the published setting |
| Service unavailable | The latest [maintenance notice](/maintenance) | Wait for the announced completion instead of repeatedly reinstalling |
| Steam reports damaged or missing files | Main-game Library entry | Use Library → Properties → Installed Files → Verify integrity of game files |
| Installation cannot finish | Free space on the selected drive | Follow the launcher's current storage message; do not equate a video download size with the requirement |

The file-verification path is documented by [Steam Support](https://help.steampowered.com/en/faqs/view/0C48-FCBD-DA71-93EB). If the problem persists, record the exact error, launcher, region and time for [official AION 2 support](https://help.plaync.com/faq/aion2global). A TW configuration-file path is not a verified Global fix.
