# 四语攻略配图与阅读体验实施记录

实施日期：2026-10-03。范围：优先清单的 20 个主题 × 英、日、西、德，共 80 篇。关键词、分类、slug 和既有目录锚点保持不变。三个 subagent 分别负责战斗、成长和账号/运营主题，主 agent 负责共享组件、整合和验收。

## 内容与配图

- 80 篇同步增加本地化图注、说明图、实用案例、问题排查和下一篇入口。各主题保留独立研究日志；原始素材、Discord 导出和旧 research 文件未覆盖。
- 新增 28 条图片来源记录，位于 `src/content/guide-assets.json`；36 个本地图片文件共 7,801,605 字节，其中包含八职业桌面版原图备份。文件总量不等于单页下载量。
- 职业页用八职业官方画像、徽记和职责卡片；八张画像视为一组。其他页面使用官方世界图、Steam 游戏画面、官方奖励图，以及 Aion2T 和 Style Shop 的真实公共网页截图。
- 20 个主题均有原生 HTML 操作说明图，四语独立翻译。维护、付费主题使用说明图；没有制作虚构客户端截图。官方画像只表达职业身份，不证明技能配置或实测强弱。
- 深化新手的首次会话清单、升级卡关判断、采集材料核对与试跑、职业选择练习、Chanter/Cleric 组队职责、配置重置排查、PvP 练习和 Rift 时间窗口辨别。
- 采集新增 Global 玩家现场记录的具体案例，清楚标注作者、地区和日期；地图截图的标记不表示实时刷新。Style Shop 截图只证明公共浏览与筛选，不证明当前客户端购买、应用或导入流程。
- 运营页复核公告、兑换码、Drops、服务器、Steam 和购买条款。现行 Global 来源优先；测试服、KR/TW、作者推荐和客户端未验证细节仍在正文标明适用范围。

逐主题材料保存在本目录下对应 slug 文件夹；素材来源的地区、版本、核对日、冲突与限制随研究记录及来源清单保存。视频时间点仅保存在研究日志。

## 阅读与互动

- 手机正文 16px、表格和目录 14px；目录默认收起，并高亮当前章节。主要控件满足 44px 触控高度，表格保留横向滚动提示。
- 图片按实际尺寸预留空间，通过 Next Image 生成响应式版本；默认延迟加载。原图在点击放大后加载，支持关闭按钮、Escape、背景关闭、键盘焦点约束和返回触发按钮。
- 新手 8 项、下载 7 项可勾选清单；按主题存储，四语共享进度，可以重置。存储完全受限或可读但不可写时，仍可在当前页面勾选。
- 职业职责筛选、升级阵营筛选、服务器地区筛选。目录访问隐藏章节时自动恢复可见；重复点击当前同一锚点也可恢复。无 JavaScript 时仍输出全部正文、来源、图片与分组。
- 正文及来源列表之前增加下一篇卡片，使用本地化摘要说明内容。卡片与页尾相关链接去重；职业卡片跳至角色选择段落或对应攻略。
- 未接入统计，未声称停留时间或跳出率已经改善。本轮提供便于继续阅读和完成任务的页面行为，实际效果需后续访问数据验证。

## 验收

- `npm run check`：ESLint 与 TypeScript 通过。
- `npm run test:content`：80 篇、28 条素材来源、四语组件对应、来源链接、图注、清单、锚点、编码校验通过。
- `npm run build`：生产构建通过，生成 96 个静态路径。
- `npm run test:smoke`：100 项页面检查、84 项 sitemap、语言替代、重定向、404、robots 与资源通过。
- `npm run test:browser`：80 篇四语页面通过，另测图片放大键盘/焦点、清单重载/跨语/重置/存储异常、筛选/同锚点恢复、移动目录、语言切换保留查询与 hash、兑换码及溢出。无运行时、控制台或本站资源请求错误。桌面与手机截图位于 `.qa/`。
- 人工检查职业卡片、Chanter 画像、采集流程和地图截图，确认本地化说明、来源标记与手机可读性。

独立只读审查发现并修复：存储回退覆盖、同一锚点不触发恢复、目录高亮偏移、图片弹窗居中与键盘焦点；同时修正职业卡片的段落跳转和一处德语表达。

## 性能与预览

性能采样使用 Chrome 390×844、冷缓存、150ms 延迟、1.6Mbps 下载、CPU 4 倍降速，每个页面三次。前后数据在 `.qa/performance-before.json` 与 `.qa/performance-after.json`；统计字节范围是 Resource Timing 的子资源，不含 HTML 文档。这是本机实验，不代表真实访客 Core Web Vitals。

| 页面 | 改造前 LCP 中位数 | 改造后 LCP 中位数 | 改造前/后子资源 kB 中位数 | 改造后 CLS |
| --- | --- | --- | --- | --- |
| guide | 900ms | 1104ms | 194.5 / 212.8 | 0 |
| classes | 852ms | 1052ms | 194.5 / 288.2 | 0 |
| map | 996ms | 1148ms | 194.5 / 232.1 | 0 |

新增互动和配图后，这三个手机首屏的 LCP 中位数增加 152–204ms，均约 1.05–1.15 秒，未观测到布局偏移。资源增加已记录；这组实验不测完整页面滚动后的总流量，也不证明真实访客的性能或阅读行为改善。可运行 `npm run test:performance` 重现当前采样。
