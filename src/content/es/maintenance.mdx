<h2 id="check-current-status">Comprueba el estado que afecta a tu acceso</h2>

1. Abre los anuncios oficiales y lee el aviso más reciente que corresponda a tu región.
2. Comprueba si describe una ventana prevista, una interrupción activa o una recuperación.
3. Compara la fecha y la zona horaria del aviso con la hora actual.
4. Busca una hora de finalización actualizada o un mensaje posterior de recuperación.
5. Si no se anuncia una interrupción relevante, compara tu error con las comprobaciones de cuenta y cliente siguientes.

Una hora de finalización estimada es una previsión. Un aviso posterior de recuperación aporta una confirmación más sólida de que el evento terminó. No interpretes un mensaje antiguo de inicio como el estado más reciente si ya se publicó una recuperación.

Usa el [Discord oficial](https://discord.gg/aion2official) como otro canal de anuncios. Lee la región antes de aplicar un aviso de Corea o Taiwán a Global: los calendarios regionales pueden ser diferentes.

<h2 id="login-or-account-error">¿Mantenimiento o problema de cuenta y cliente?</h2>

| Qué ocurre | Siguiente acción útil |
| --- | --- |
| Hay una interrupción oficial actual | Sigue la región afectada y la última actualización de ese aviso. |
| Se rechaza tu derecho de acceso anticipado | Reinicia el cliente para cargar la corrección publicada por NC; comprueba la cuenta que posee el acceso. |
| Problema de compra después de actualizar | Compáralo con el aviso de corrección de compras y contacta con soporte si continúa. |
| Falta un personaje tras cambiar vínculos de cuenta | Sigue la guía oficial de vinculación en lugar de añadir más conexiones. |
| Descarga completa pero sin acceso | Comprueba los requisitos del acceso anticipado y el calendario de apertura pública. |

El 1 de octubre, NC anunció correcciones para algunos problemas de reconocimiento del acceso anticipado y de compras dentro del juego. **Esa actualización no necesitaba una interrupción:** se aplica al reiniciar el cliente. El mismo aviso indicaba que se investigaban problemas de vinculación de cuentas. [Actualización oficial sobre cuentas y compras](https://aion2.plaync.com/en-us/board/notice/view?articleId=6abe2cf8a7ca1a15cf46bcbe).

La [guía de vinculación](https://aion2.plaync.com/en-us/board/notice/view?articleId=6abf40d99ed1202b9b8fb4fb) de NC del 2 de octubre advierte que vincular otra cuenta NC por separado puede eliminar la conexión existente y afectar al acceso a personajes. Por tanto, un personaje ausente no demuestra por sí solo que haya mantenimiento. Consulta [Steam](/steam) y [Twitch Drops](/twitch-drops) para identificar la cuenta correcta.

<h2 id="report-unresolved-errors">Si sigues sin poder conectar</h2>

Anota el error exacto, la región, el servidor, el método de inicio de sesión de Steam o PURPLE y la hora con su zona horaria. Reinicia una vez si sigues una instrucción publicada para corregir el cliente y comprueba si cambia el error. Consulta la [guía de descarga](/download) para comprobar el lanzador y la instalación.

Si los avisos oficiales no explican el fallo, envía esos datos al [soporte de AION 2](https://help.plaync.com/faq/aion2global). Ninguna fuente comprobada para esta página garantiza un tiempo de respuesta, una fecha universal de recuperación o que se hayan corregido todos los problemas de cuentas privadas.
