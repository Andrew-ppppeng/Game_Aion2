<h2 id="link-and-claim">正しいアカウントを連携して受け取る</h2>

1. [公式Twitch Dropsページ](https://aion2.plaync.com/en-us/twitchdrops/index)を開く。
2. AION2のログイン方法を確認する。**SteamプレイヤーはSteam、PURPLEプレイヤーはNCアカウントを連携する。**
3. 変更前にMy Page → Manage Loginで現在の接続を確認する。
4. Twitchにログインし、対象のAION2チャンネルを視聴する。
5. インベントリの進捗を見て、報酬が使えるようになったらClaimで受け取る。

NCは、同じキャンペーンの対象チャンネル間で進捗を引き継げると確認しています。配信を変えても視聴時間は最初からにはなりません。[公式FAQ](https://aion2.plaync.com/en-us/twitchdrops/index)。

10月2日、NCは別の認証方法を連携すると報酬が違うアカウントに送られる場合があると説明しました。**報酬が届かなくても、応急処置としてNCサイトに別アカウントを追加連携しないでください。** 既存接続が解除され、現在のキャラクターにアクセスできなくなる可能性があるとしています。[アカウント連携案内](https://aion2.plaync.com/en-us/board/notice/view?articleId=6abf40d99ed1202b9b8fb4fb)に従いましょう。

<h2 id="missing-drops">進捗や報酬がない場合</h2>

| 症状 | 最初の確認 |
| --- | --- |
| 視聴進捗が増えない | 開催中キャンペーンの対象チャンネルか確認し、Twitchインベントリを見る |
| 目標達成したが未受取 | 開催中にインベントリで受け取る |
| 受取済み報酬がゲームにない | 連携したSteam・NC認証とキャラクターのアカウントを照合する |
| 変更後に既存キャラクターが見えない | 追加変更を止め、NCの連携案内・サポート手順に従う |
| KR/TWキャラクターに届かない | 今回のGlobal企画はその地域のサーバーを含まない |

[公式FAQ](https://aion2.plaync.com/en-us/twitchdrops/index)は、対象者が受取済み報酬を得られない場合に[サポート](https://help.plaync.com/faq/aion2global)を案内しています。キャンペーン、報酬、受取時刻、ゲーム地域、ログイン方法を添えてください。確認資料には共通の配信時間保証や、全アイテムのキャラクター・サーバー制限表はありません。

ゲーム内メールと[クーポン報酬](/code)は別の受取経路です。一つで成功しても、他の経路の配信が確認されたことにはなりません。
