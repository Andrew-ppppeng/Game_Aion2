キャラクター作成前に、仲間と**地域・種族・サーバー**を合わせましょう。Globalの各サーバーは一つの種族を収容し、敵種族のサーバーと組み合わされます。以下は2026年10月2日に更新されたNC公式告知の名簿と組み合わせであり、現在の人口や作成状況をリアルタイムに示すものではありません。[公式サーバー案内](https://aion2.plaync.com/en-us/board/notice/view?articleId=6ab85cc646be804931c31335)。

<h2 id="choose-with-friends">仲間とサーバーを決める</h2>

1. まずNA West、NA East、Europe、South America、Asiaから地域を決める。
2. 天族か魔族かを合わせる。種族で表示されるサーバー一覧が変わる。
3. 全員が先行プレイか正式サービス開始から参加するかを確認する。
4. 同じ地域・種族内で第一希望と予備のサーバーを選ぶ。
5. 計画を確定する前に、クライアントの現在の作成可否を確認する。

NCは希望サーバーに待機列がある場合、推奨サーバーも検討するよう案内しています。名簿に載っていても、ログイン時にキャラクター作成が開放されているとは限りません。[公式の待機列・移転案内](https://aion2.plaync.com/en-us/board/notice/view?articleId=6abd2d50a279104f7d9d5ee2)。

確認した資料には、裏付けのある人口・遅延ランキングはありません。未計測の「最適サーバー」という表示を保証と考えず、仲間に合う地域を選んで自分の接続を確認してください。

<h2 id="cross-server-play">敵サーバーの組み合わせとサーバー間プレイ</h2>

組み合わせは、Spacetime Riftsやアビスで出会う敵種族を決めます。NCは一時的な組み合わせを定期的に調整すると説明しています。現在の相手が永続するとは限りません。[マッチングの説明](https://aion2.plaync.com/en-us/board/notice/view?articleId=6abab930eea53f5d6dbcf939)。

NCは別途、ダンジョンなどのインスタンスをサーバー間で遊べると確認しています。これは地域をまたぐグループや、全サーバー共通のフィールドを意味しません。フィールドで一緒にクエストを進めるなら、地域・種族・サーバーを合わせましょう。[公式のサーバー間プレイ説明](https://aion2.plaync.com/en-us/board/notice/view?articleId=6abd2d50a279104f7d9d5ee2)。

モードの違いは[PvPガイド](/pvp)、敵種族の地域への移動は[裂隙ガイド](/spacetime-rift)を参照してください。

<h2 id="transfer-rules">サーバー移転と正式サービス開始</h2>

| 質問 | 発表されたルール |
| --- | --- |
| 移転開始はいつか | 2026年10月14日 |
| 移転で種族を変更できるか | 発表された移転は同じ種族内に限定 |
| 当初の費用は | 当初は無料。無料期間の終了日はここでは未発表 |
| 先行プレイのキャラクターは正式開始用サーバーへ移れるか | 不可。先行プレイのキャラクターは先行プレイ用サーバー内に限定 |

これらは[Information on Server Transfer](https://aion2.plaync.com/en-us/board/notice/view?articleId=6abd2d50a279104f7d9d5ee2)に基づきます。地域をまたぐ移転は確認されていません。後の種族変更や新設サーバーへの自由な移動を前提に作成しないでください。

一般向けの開始は、予定メンテナンス05:00～13:00 UTC後の**10月5日13:00 UTC**です。メンテナンス時間は変わる場合があります。初日の予定を組む前に[メンテナンス情報](/maintenance)と[公式開始日程](https://aion2.plaync.com/en-us/board/notice/view?articleId=6ab85cc646be804931c31335)を確認しましょう。
