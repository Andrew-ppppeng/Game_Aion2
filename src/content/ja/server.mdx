キャラクター作成前に仲間と**地域・種族・サーバー**を合わせましょう。Globalの各サーバーは一つの種族に対応し、種族間コンテンツでは敵種族のサーバーと組み合わされます。

<GuideVisual id="workflow" />

<h2 id="choose-with-friends">仲間とサーバーを決める</h2>

1. まずNA West、NA East、Europe、South America、Asiaから地域を決める。
2. 天族か魔族かを合わせる。種族で表示されるサーバー一覧が変わる。
3. 全員が先行プレイか正式サービス開始から参加するかを確認する。
4. 同じ地域・種族内で第一希望と予備のサーバーを選ぶ。
5. 計画を確定する前に、クライアントの現在の作成可否を確認する。

第一希望に待機列がある場合は同じ地域・種族の推奨サーバーも候補にしましょう。全員が決める前に、クライアントでキャラクター作成の可否を確認してください。

仲間の居住地と普段のプレイ時間に合う地域を選び、接続状況も確認しましょう。

<h2 id="cross-server-play">敵サーバーの組み合わせとサーバー間プレイ</h2>

組み合わせはSpacetime Riftsとアビスで出会う敵種族のサーバーを決め、定期的に調整されます。

ダンジョンなどのインスタンスはサーバー間で遊べます。フィールドで一緒にクエストを進める場合は地域・種族・サーバーを合わせてください。

モードの違いは[PvPガイド](/pvp)、敵種族の地域への移動は[裂隙ガイド](/spacetime-rift)を参照してください。

<h2 id="transfer-rules">サーバー移転と正式サービス開始</h2>

| 質問 | 移転ルール |
| --- | --- |
| 移転開始はいつか | 2026年10月14日予定 |
| 種族を変更できるか | 同じ種族内でのみ移転可能 |
| 当初の費用は | 当初は無料 |
| 先行プレイのキャラクターは正式開始用サーバーへ移れるか | 不可。先行プレイのキャラクターは先行プレイ用サーバー内に限定 |

移転後も種族は同じで、先行アクセスのキャラクターは当初、先行アクセスサーバー内でのみ移転できます。この条件に合わせて種族とサーバーを選びましょう。

一般公開は05:00～13:00 UTCのメンテナンス後、**10月5日13:00 UTC**予定です。初日の予定を組む前に[メンテナンス情報](/maintenance)で変更を確認してください。

グループを作る前に[種族比較](/races)を確認しましょう。[サーバー移転ガイド](/server-transfer)は10月14日開始予定、同じ種族の条件、初期の先行アクセス制限をまとめています。
