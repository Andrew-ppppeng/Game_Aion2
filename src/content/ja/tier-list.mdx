現在比較できるAION2のTierリストには大きな違いがあります。CrusherXGamingはスピリット マスターをS+、WigglesはDに置いています。別々の作者が異なる問いを評価した結果です。表は遊ぶ内容に合う候補を絞るために使い、Global公式のダメージ順位と考えないでください。

<h2 id="what-each-list-measures">それぞれが何を評価しているか</h2>

CrusherXGamingは、序盤ソロの快適さ、パーティー貢献、アビスでの有用性を合わせてGlobal開始時の推奨を作っています。レンジャーの話はレベル37のテストを参照し、最大レベルをそろえた比較ではありません。動画内の開始時ルールの主張も、順位と並んでいるだけで確認済み情報になるわけではありません。

Wigglesは、KRとTWそれぞれのPvEランキング4分類から上位100件を取ったと説明しています。合計800件ですが、同じキャラクターが複数分類に載る可能性があり、800人の独立プレイヤーとは確認されていません。出現数に生存、攻撃継続、グループ貢献の判断を加えたもので、全プレイヤーの無作為標本でもGlobalの直接的なダメージ測定でもありません。[元の説明](https://www.youtube.com/watch?v=mCxLbeDusUg)を確認してください。

両動画は2026年10月2日に確認しました。正確なクライアント版と、独立して再現できるテスト条件は未確認です。評価を共有する際も、この制限を一緒に伝えましょう。

<h2 id="spiritmaster-and-ranger">スピリット マスターとレンジャーが割れる理由</h2>

CrusherXGamingはスピリット マスターの召喚による序盤ソロの安全さと、アビスでの制御を重視します。Wigglesは競争的PvEの結果を中心に、地域ランキングの出現数が少ないと報告しています。快適なクエストと強い制御が、最速ボス討伐になるとは限らないため、両方の観察は両立し得ます。

レンジャーもBとSに分かれます。レベル制限付きテストと後の地域ランキングでは、成長、装備、戦闘条件が異なります。違いは実演とパッチ背景を調べる理由として使い、どちらかが普遍的な正解を得た証拠としないでください。両評価の平均から新しい数値順位を作る根拠もありません。

<h2 id="choose-for-your-content">自分の遊ぶ内容に合わせる</h2>

| 優先する内容 | 選ぶ前に比較すること |
| --- | --- |
| ソロクエストと探索 | 回復、安全な敵の集め方、移動、基本連携を楽しめるか |
| グループダンジョンの練習 | タンクの位置取り、回復、解除、防御、安定したギミック対応 |
| 固定グループの高速攻略 | 全体への利益、攻撃継続、効果の重複、戦闘の実行 |
| 決闘や少人数戦 | 接近、制御、離脱、反応できるか |
| 大規模PvP | 仲間との行動、連携した制御、支援範囲、生存 |

これは選択の基準であり、追加のTierリストではありません。仲間に攻撃役がそろっているなら、混合評価の最高位より不足した役割が有用な場合があります。[8クラスの特徴](/classes)を比べてから[序盤ビルド](/builds)を確認してください。PvPではPvE順位を使う前に[モードガイド](/pvp)を読みましょう。

<h3>選択例：初ソロキャラとしてのスピリット マスター</h3>

クエストと探索が中心で、ときどきダンジョンに行くとします。CrusherXGamingのS+は、召喚を使ったソロの快適さという作者の見方に関係します。一方、WigglesのDは地域版の競争的PvEについての評価です。召喚の管理が好きなら候補に残しましょう。決める前に、移動が必要な戦闘を見て、自分の攻撃と召喚をギミック対応と両立できそうかを確認します。この操作の相性は、どちらの文字でも答えられません。

目標が、より速いPvEクリアを目指す固定グループに変わった場合は、自分が到達する成長段階の戦闘全体を、編成と装備が見える資料で確認します。Wigglesの地域版サンプルはその条件を調べる理由ですが、Globalの新キャラクターではダンジョンをクリアできない証拠ではありません。

<h3>選択例：レンジャーのBとS</h3>

序盤向けの列がBという理由だけでキャラクターを変えないでください。レベル制限のあるテストと後期地域版の条件を比べ、自分の戦闘では移動中の攻撃停止、未開放設定、ギミック失敗のどれが問題なのかを確認します。距離の維持が原因なら、別クラスに投資する前に位置取りを変えて試しましょう。

**両作者がAなら同じ強さ？** いいえ。文字は同じ火力、責任、操作難度を示しません。テンプラーとクレリックは別のパーティー問題を解決します。

**PvPにはどちらの列を使う？** WigglesのPvE評価は対人評価ではありません。モードごとの実戦と味方の必要性を確認します。複数用途を混ぜた序盤評価も、条件を揃えたPvP測定ではありません。

<h2 id="test-before-rerolling">作り直す前に試すこと</h2>

まず実際に開放した設定でクラスを試し、同じ戦闘を複数回行いましょう。失敗がギミック、攻撃継続、回復不足、未完成設定のどれかを記録します。レベルと装備を近づけ、パーティー効果の有無も残してください。短いソロ木人テストを全体貢献と同一視しないことが大切です。

バランス変更後は地域と日付を再確認します。NCの[3月25日の地域版更新](https://about.ncsoft.com/en/news/article/aion2_update_260325)はクラス、Stigma、PvE/PvP計算を変えており、古い設定やテストが合わなくなる例です。役割と操作が合うなら続け、別のスタイルで解決できる具体的な問題を見つけてから変更しましょう。
