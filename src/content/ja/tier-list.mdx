<h2 id="what-each-list-measures">序盤の快適さと競争的PvE</h2>

Global開始時の列は序盤ソロの快適さ、パーティー貢献、アビスでの有用性を合わせています。KR/TWの列はランキングへの登場、生存、攻撃継続など、競争的PvEを重視しています。

<h2 id="spiritmaster-and-ranger">スピリット マスターとレンジャーの選び方</h2>

スピリット マスターは属性精霊、遠距離攻撃、行動妨害を組み合わせます。精霊の効果を管理して開幕を組み立てるのが好きな人に向いています。ボス戦では移動中の効果維持とギミック後の攻撃再開を練習しましょう。

レンジャーは遠距離物理攻撃が中心です。安全な射撃位置とMPを保ち、条件を満たした追撃を使いましょう。B/Sの差には、レベル制限付き開始前テストと後期KR/TWの成長段階の違いがあります。

<h2 id="choose-for-your-content">自分の遊ぶ内容に合わせる</h2>

| 優先する内容 | 選ぶ前に比較すること |
| --- | --- |
| ソロクエストと探索 | 回復、安全な敵の集め方、移動、基本連携を楽しめるか |
| グループダンジョンの練習 | タンクの位置取り、回復、解除、防御、安定したギミック対応 |
| 固定グループの高速攻略 | 全体への利益、攻撃継続、効果の重複、戦闘の実行 |
| 決闘や少人数戦 | 接近、制御、離脱、反応できるか |
| 大規模PvP | 仲間との行動、連携した制御、支援範囲、生存 |

仲間に攻撃役がそろっているなら、自分が楽しめる不足した役割を選びましょう。[8クラスの特徴](/classes)と[序盤ビルド](/builds)を比べてください。対人戦では[PvPモード](/pvp)とチームの必要性に合わせます。

<h3>選択例：初ソロキャラとしてのスピリット マスター</h3>

クエスト、探索、ときどきのダンジョンなら、精霊管理を楽しめる人はスピリット マスターを候補に残しましょう。移動する戦闘で自分の攻撃と召喚を両立させます。瞬間火力一つより、使いやすい召喚連携が判断に役立ちます。

固定グループで高速攻略を目指すなら、攻撃継続、仲間の強化、ギミックを重視します。戦闘全体を練習し、貢献が途切れる場面と、それを改善する調整を見つけましょう。

<h3>選択例：レンジャーのBとS</h3>

レンジャーを変える前に、移動での攻撃停止、使えない追撃、ギミック失敗のどれが問題かを確認します。距離の維持が原因なら、別キャラクターへの投資より先に位置取りと防御操作を改善しましょう。

**同じTierなら役割も同じ？** いいえ。テンプラーは前衛の制御と位置取り、クレリックは回復・解除・立て直しを担当します。

**PvPでは何を比べる？** 接敵、行動妨害、離脱、支援と、チームが確保したい目標を比べます。

<h2 id="test-before-rerolling">作り直す前に試すこと</h2>

まず実際に開放した設定でクラスを試し、同じ戦闘を複数回行いましょう。失敗がギミック、攻撃継続、回復不足、未完成設定のどれかを記録します。レベルと装備を近づけ、パーティー効果の有無も残してください。パーティーでは強化、回復、それで仲間が攻撃できる時間も比べます。

役割と操作が合うならメインを続けましょう。新しいスキル設定を開放したら、構成とタイミングを調整してから再び判断します。

[グラディエーター](/gladiator)、[レンジャー](/ranger)、[スピリット マスター](/spiritmaster)で序盤スキルと実戦の判断を比べましょう。
