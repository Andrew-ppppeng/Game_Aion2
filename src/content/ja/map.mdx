<h2 id="choose-map">目的に合ったインタラクティブマップを選ぶ</h2>

資源ルートには絞り込みできるマップを、上下にある地点には高さがわかるマップを使いましょう。AION 2には高い足場や洞窟があるため、目的地だけでなく接近経路も計画します。

| ツール | 用途 | 便利な操作 |
| --- | --- | --- |
| [Aion2T Interactive Map](https://aion2t.com/map) | 資源・収集物のルート | エリア選択、検索、分類フィルター |
| [Aion2Maps](https://www.aion2maps.com) | 高さ、洞窟入口、収集進捗 | ボクセル地形表示、進捗同期コード |
| [Aion2Hub Maps](https://aion2hub.com/maps) | 別の資源・エリアマップ | フィルターとルート計画 |

旧`aion2.app/map`はAion2Tに転送されます。ツールでサービス地域を選び、不明な地点はゲーム内マップと照合してください。

<h2 id="faction-zones">種族とエリアを合わせる</h2>

天族のマップは**Verteron**、魔族は**Altgard**です。Dawn Legion BaseとCantas Valleyは天族、Safe HavenとMoslan Forestは魔族の目印です。

1. キャラクターの種族とゲーム内のエリア名を確認する。
2. 外部マップで対応するエリアを選ぶ。
3. 無関係な分類を消し、必要な資源・収集物だけを表示する。
4. 地点を追う前に、近くの目印や移動地点を照合する。
5. 敵種族の地域に入る場合は、通常の採集ルートと考える前に[PvP・裂隙の条件](/spacetime-rift)を確認する。

<h2 id="ingame-filters">ゲーム内マップで探索情報を表示する</h2>

大きなマップのフィルター設定で探索情報を表示します。**Filter Settings → Content**または自分の言語の対応項目を探してください。表示レイヤーが非表示だと、外部マップの収集物がゲーム内では見えない場合があります。

- 大きなマップの設定を調べてから、収集物がないと判断する。
- 必要な表示を有効にし、拡大して近くのアイコンを見分ける。
- ゲーム内とコミュニティマップの地点を、見える目印と照合する。
- 回収済み・未回収の表示が使える場合は利用し、終わった地点を繰り返さない。

育成中は近くの収集物を回収しましょう。専用の収集時間にはエリアごとに進め、収集画面で完了状態を管理します。

<h2 id="resource-route">採集・収集ルートを作る</h2>

<GuideVisual id="workflow" />

1. 製作素材、探索収集物、未完了ダンジョン・移動地点などから目標を1つ選ぶ。
2. その目標に絞り、既知の開始地点の近くにある小さな集まりを選ぶ。
3. 直線距離だけでなく地形で順序を決める。坂、洞窟入口、飛行経路を確認する。
4. 現在のマップのマーカー枠に合わせ、無理のない数の地点を登録する。
5. 一度回り、採集失敗、通れない地点、未出現地点を記録してからルートを直す。

資源採集では収量と所要時間を記録して有用性を判断します。マップは出現候補を示します。資源がない地点は飛ばして次へ進みましょう。素材選びと条件確認は[採集ガイド](/gathering)を参照してください。

**天族の絞り込み例：** [Aion2T](https://aion2t.com/map)で**Global → Verteron**を選び、**Hide All**を押します。**Herbs**を有効にし、**Targena**をオフにして**Aria**だけを残します。魔族では先に**Altgard**を選んでください。マップは出現候補を示すので、到着後に採集条件を確認しましょう。

<h2 id="map-troubleshooting">見つからない地点と進捗の問題を解決する</h2>

| 問題 | 対応 |
| --- | --- |
| マーカー上にいるのに何も見えない | 高さ、洞窟、近くの進入路を確認し、ボクセルマップで上下位置を調べる |
| 資源が表示されない | エリア、分類、検索条件を確認し、ゲーム内の採集条件と比較する |
| 宝箱や採集地点がない | 出現候補として扱い、固定の再出現時間を仮定せず次へ進む |
| 同じ収集物がルートに残る | ツールで完了を記録し、ゲーム内進捗と比較する |
| 端末間で進捗が違う | 利用できる同期・書き出し手順を使い、ブラウザデータ削除前に復元情報を保存する |

端末の切り替えやブラウザデータの削除前に、Aion2Mapsの進捗同期コードを保存しましょう。長い収集では完了エリアを別にも記録します。座標の誤りはエリア名とゲーム版を添えて報告してください。
