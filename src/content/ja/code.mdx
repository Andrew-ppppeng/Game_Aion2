<h2 id="coupon-rewards">Globalクーポンで受け取れるもの</h2>

確認済みクーポンには以下のアイテムが含まれます。すべてBoundで、取引できません。NCは**全サーバーを通じて1アカウントにつき1回**の交換としています。別のキャラクターを作成したり、サーバーを変更したりしても、同じクーポンを再利用することはできません。[公式の報酬・利用規則](https://aion2.plaync.com/en-us/board/notice/view?articleId=6abd5fe5fa7da41c727d63c6)。

| 報酬 | 数量 | 帰属表記 |
| --- | --- | --- |
| Odyle Energy | 4 | Bound |
| Resurrection Spiritstone | 5 | Bound |
| Battle Enhance Scroll | 10 | Bound |

別のキャンペーン画像だけを頼りにせず、アイテム名と数量を確認しましょう。このクーポンのスクロール10個は、後述するメール配布の5個とは別です。公式英語表記を残しているため、告知とクライアントのアイテム説明を照合してください。

<h2 id="redeem-coupon">クーポンの交換手順</h2>

NCの案内するゲーム内経路は**Settings → Miscellaneous → Account → Enter Coupon**です。[公式の手順](https://aion2.plaync.com/en-us/board/notice/view?articleId=6abd5fe5fa7da41c727d63c6)。

1. Globalクライアントを起動し、実際にプレイするアカウントでログインします。
2. Settingsを開き、Miscellaneous、Accountへ進みます。
3. Enter Couponを選びます。
4. 上のカードからクーポンをコピーし、前後に余計な空白がないか確認します。
5. Confirmを選び、再試行する前に表示された結果を読みます。

先行アクセス期間は、クライアントを導入しただけではプレイできません。交換メニューまで進めない場合は、利用資格と[Steamガイド](/steam)を確認してください。Global一般公開は10月5日13:00 UTCの予定ですが、これはクーポンの有効期限とは別の時刻です。[公式の利用日程](https://aion2.plaync.com/en-us/board/notice/view?articleId=6ab85cc646be804931c31335)。

<h2 id="redemption-problems">クーポンが拒否された場合</h2>

同じ操作を繰り返す前に、クライアントのエラーから原因を絞り込みましょう。

| 確認事項 | 操作 |
| --- | --- |
| 対象地域 | Globalでプレイしているか確認する。KR/TWのキャンペーンはGlobalで使える根拠にならない |
| 入力内容 | 最後の文字までカードと照合し、コピーした空白を削除する |
| 告知の期限 | 上の有効期限と公式告知を、タイムゾーンを含めて確認する |
| 使用履歴 | このアカウントですでに交換していないか確認する。回数は全サーバー共通 |
| ログイン・サービス問題 | ログイン失敗をコード無効と判断する前に、最新の[メンテナンス情報](/maintenance)を読む |

これらの確認だけで報酬の配送が証明されるわけではありません。結果が不明な場合は、正確なエラー、地域、ログイン方法、試行したおおよその時刻を[AION2サポート](https://help.plaync.com/faq/aion2global)に伝えてください。エラー報告にパスワードや認証コードを公開しないようにしましょう。

<h2 id="other-reward-methods">その他の開始記念報酬は別に受け取る</h2>

NCはゲーム内メールで**Battle Enhancement Scroll (Engraved) ×5**も告知し、先行アクセス終了まで受け取り可能としています。メールの贈り物なので、クーポン入力では受け取れません。この告知にある異なる名称と帰属表記をそのまま記載しています。[公式のメール配布告知](https://aion2.plaync.com/en-us/board/notice/view?articleId=6abe7e2f49d41d00dc124c83)。

| 報酬の種類 | 受け取りの開始場所 |
| --- | --- |
| 確認済みGlobalクーポン | ゲーム内のEnter Couponメニュー |
| 告知されたメールの贈り物 | ゲーム内メールボックス |
| Twitch Drops | Twitchのインベントリと、正しく連携したゲームアカウント |

視聴条件やアカウント連携は[Twitch Dropsガイド](/twitch-drops)を確認してください。Twitch報酬の受け取りで、このクーポンも自動交換されるわけではありません。

<h2 id="regional-coupons">Global・韓国・台湾のコードを区別する</h2>

コードを共有するときはキャンペーンの地域も添えましょう。上のGlobal一覧は、リンクしたGlobal公式告知で裏付けられるクーポンのみです。各地域のキャンペーンを一括した一覧ではありません。

以前の[コミュニティ報告](https://discord.com/channels/1113589630122606594/1113589937682526321/1552191574727721031)には、韓国と台湾それぞれの9月23日のお祭りクーポンが記載されています。歴史的な参考資料ですが、Global向けのキャンペーンになるわけではありません。地域別コードを使う前に、その地域の公式告知で報酬、利用回数、メンテナンスに伴う有効期限を確認してください。タイムゾーンのない日付を、自国の午前0時と解釈しないようにしましょう。

本ページの調査では個人アカウントでクーポンを交換していません。確認済みという表示は、公式告知を根拠とするもので、ゲーム内交換テストの結果ではありません。
