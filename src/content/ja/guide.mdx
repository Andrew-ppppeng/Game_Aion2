<h2 id="start-global">Globalのアカウントとサーバーを確認する</h2>

AION2 GlobalはSteamとPURPLEで遊べるPC向けMMORPGです。2026年10月2日現在、対象プレイヤーは先行プレイに参加でき、無料で遊べる正式サービスは10月5日開始予定です。日程とプラットフォームは[NCの10月1日発表](https://about.ncsoft.com/news/article/A2_update_20261001)に基づきます。

最初は次の順序で準備しましょう。

1. [公式クライアントのダウンロード手順](/download)に従い、更新を完了する。
2. 一緒に遊ぶ人と地域、種族、正確な[サーバー](/server)名を合わせる。
3. 他地域の順位だけで決めず、好きな役割の[クラス](/classes)を選ぶ。
4. [キャラクター作成](/character-creation)を終え、移動、カメラ、戦闘のキー設定を確認する。
5. メインストーリーを進め、新しいスキル設定が紹介されたら確認する。

Globalの初期8クラスは[公式紹介](https://aion2.plaync.com/en-us/about/index)で確認できます。後のKR/TW版の内容を、そのままGlobalのクラス選びや育成計画に当てはめないようにしましょう。

**最初のクエスト前に：** ポーションの自動使用、拾得対象、HUDの読みやすさを確認します。[Global Launch Scale Testのプレイヤー](https://space4games.com/en/games-en/aion-2-beginner-guide/)は**Combat → Auto Use**、**Combat → Looting**、**HUD Edit**を示しています。これはテスト版の名称です。現在の対応項目と説明を読み、未確認の閾値や自動処分フィルターをそのままコピーしないでください。

<h2 id="main-story-first">メインストーリーを育成の軸にする</h2>

レベルが十分に見えても、メインストーリーを途中で放置しないことが大切です。[TWプレイヤーの初心者向け振り返り](https://www.youtube.com/watch?v=C73KG9MvqUk)では、ストーリー完了によって次の育成要素が開放され、つなぎの武器も得られると説明しています。プレイヤーの助言として参考にし、Globalの正確なアイテム名と報酬量はクエスト画面で確認してください。

ストーリーが止まったら、周回を始める前に実際の条件を調べましょう。

| 行き詰まり | 確認すること | 次の行動 |
| --- | --- | --- |
| クエストが出ない | 前のクエストの完了状態と必要レベル | 日誌を開き、未完了の手順を終える |
| 覚醒・成長条件が不足 | 表示されたゲージや目標 | 現在のクライアントで対象となる近くの地域コンテンツを進める |
| ボスに倒される | 回避できる攻撃、武器、スキル、消耗品 | ギミックを覚えてから、必要な部分を強化する |
| ダンジョンに入れない | 現在のレベル・装備条件と開放クエスト | 無関係な数値を上げるのではなく、その条件を満たす |

[レベリングガイド](/leveling)では天族と魔族を分けて説明しています。TWの速攻ルートの目安は参考情報であり、Globalで必ず同じ順序になるとは限りません。

**例：次のストーリー目的地は見えるが進めない。** 目標を開き、「現在の目標／必要レベルまたは進行条件／次に認められる行動」を短く控えます。覚醒の進行が条件なら、対象となる地域目標を確認します。装備条件なら、現在の装備と比較します。表示条件を満たしたら同じメイン目標へ戻ります。これは原因を切り分ける方法であり、架空のGlobalクエスト順ではありません。

<h2 id="skills-and-gear">目的を決めてスキルと装備を強化する</h2>

キャラクターレベル、アイテムレベル・装備スコア、戦闘力は、それぞれ育成の別の側面を表します。装備を強化するだけではクエスト完了やキャラクター経験値の獲得にはなりません。[TWの振り返り動画](https://www.youtube.com/watch?v=C73KG9MvqUk)は、まず入場に必要な装備条件を満たし、その後にキャラクターを強くする各種システムを整えることを勧めています。

- クエスト報酬の有用な装備を使い、レア度だけでなく実際の能力を比較する。
- 新しい設定が開放されたら、よく使う攻撃、防御、支援スキルの説明を読む。
- ゲーム内のスキル連携機能が使える場合は、自分のスキルとキー設定に合わせる。他クラスの順序をそのままコピーしない。
- 明確な弱点や入場条件を解決するために強化素材を使う。序盤装備は後で交換することも考える。
- 強化の確認画面を読み、特殊な失敗ルールがある装備は特に注意する。

具体的なスキル選択は[ビルドとスキル](/builds)を参照してください。[プレイヤーによるシステム解説](https://www.youtube.com/watch?v=Tn7WKMXt5Wo)もスキルとStigmaを扱いますが、収録時点ではGlobalの設定がすべて確定していないと説明しています。

<h2 id="keep-materials">使い道がわかるまで素材を残す</h2>

普通の戦利品に見えるからといって、用途不明の素材を売ったり削除したりしないようにしましょう。[TWの初心者向け動画](https://www.youtube.com/watch?v=C73KG9MvqUk)では、探索報酬、角、革、鱗などが後の育成に使われる例を挙げています。Globalのレシピや必要量は異なる可能性があります。

バッグを整理する前に、説明、製作レシピ、育成画面を確認してください。今後の用途が不明なら、調べる間は倉庫に保管しましょう。一括保管や自動抽出を使うときは選択条件を確認し、クエストや納品に必要な装備を保護してください。古い動画のレア度フィルターは、今のキャラクターに必ず合う設定ではありません。

採集は、現在のレシピに必要な素材から始めましょう。昔の高収益ルートより、実際の強化に必要な素材を短いルートで集める方が役立つことがあります。[採集ガイド](/gathering)も参照してください。

<h2 id="exploration-checklist">普段の移動に探索を組み込む</h2>

[プレイヤーのシステム解説](https://www.youtube.com/watch?v=Tn7WKMXt5Wo)は、KR/TWの封印ダンジョン、拠点、移動地点、羽根やMonolithによる成長を紹介しています。Globalで紹介された際に確認する項目として使い、同じ報酬総量が得られると考えないようにしましょう。

| 見つけたもの | 確認すること |
| --- | --- |
| 新しい移動地点 | 有効化済みで、帰りにも使えるか |
| 近くの羽根や探索収集物 | 現在の収集進捗と対応する報酬画面 |
| 封印ダンジョン | 必要レベル、目標、一度きりの成長報酬 |
| 拠点 | 完了状態と表示された装備素材 |
| ペットなど継続的な成長要素 | 普段のクエストと並行して開放できる内容 |

育成中は近くの収集物を拾い、残りは別の時間にまとめて回収しましょう。[マップガイド](/map)で必要な表示を有効にし、洞窟内の地点と地表の地点を見間違えないようにしてください。敵種族の地域では[PvP](/pvp)の危険があります。最初のプレイで急いで向かう必要はありません。

<h2 id="next-session">次回の目標とレベル45への移行</h2>

<GuideVisual id="workflow" />

[Global公式ダンジョン紹介](https://www.youtube.com/watch?v=S_TjiOh33a4)は、サービス開始時の最大レベルが45であると確認しています。その段階で残りのストーリーと開放条件を調べてから、日常の周回を決めましょう。

各セッションの始めに公式告知、明確な育成目標1つ、画面にある報酬回数を確認してください。ストーリーの条件、スキル改善、収集エリア、次のダンジョンなど、その目標を進めましょう。動画の日課や週次任務は確認すべき画面の参考になりますが、このガイドは未確認のGlobalリセット時刻やアカウント制限を指定しません。

利用できる[公式コード](/code)と[Twitch Drops](/twitch-drops)は、対応するアカウントで受け取りましょう。終了前にバッグの空き、次のクエスト、次の活動の条件を確認すれば、次回も無理なく始められます。
