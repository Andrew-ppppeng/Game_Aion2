<h2 id="start-global">Globalのアカウントとサーバーを確認する</h2>

AION 2 GlobalはSteamとPURPLEで遊べるPC向けMMORPGです。先行プレイには対象の利用権が必要で、無料で遊べる正式サービスは**2026年10月5日**開始予定です。

最初は次の順序で準備しましょう。

1. [公式クライアントのダウンロード手順](/download)に従い、更新を完了する。
2. 一緒に遊ぶ人と地域、種族、正確な[サーバー](/server)名を合わせる。
3. 好きな役割の[クラス](/classes)を選ぶ。
4. [キャラクター作成](/character-creation)を終え、移動、カメラ、戦闘のキー設定を確認する。
5. メインストーリーを進め、新しいスキル設定が紹介されたら確認する。

**最初のクエスト前に：** ポーション自動使用、拾得対象、HUDの読みやすさを確認します。**Combat → Auto Use**、**Combat → Looting**、**HUD Edit**または自分の言語の対応項目を探してください。手持ちに合わせて使用条件を設定し、自動拾得・処分の対象を確認してから有効にしましょう。

<h2 id="main-story-first">メインストーリーを育成の軸にする</h2>

メインストーリーを進め、クエスト画面で報酬と開放条件を確認しましょう。キャラクターレベルだけではストーリー進行の代わりになりません。新しいコンテンツが開いたら、導入を終えてから周回を始めます。

ストーリーが止まったら、周回を始める前に実際の条件を調べましょう。

| 行き詰まり | 確認すること | 次の行動 |
| --- | --- | --- |
| クエストが出ない | 前のクエストの完了状態と必要レベル | 日誌を開き、未完了の手順を終える |
| 覚醒・成長条件が不足 | 表示されたゲージや目標 | 現在のクライアントで対象となる近くの地域コンテンツを進める |
| ボスに倒される | 回避できる攻撃、武器、スキル、消耗品 | ギミックを覚えてから、必要な部分を強化する |
| ダンジョンに入れない | 現在のレベル・装備条件と開放クエスト | 無関係な数値を上げるのではなく、その条件を満たす |

種族別の育成と次の優先目標は[レベリングガイド](/leveling)を参照してください。

**目的地は見えるが進めない：** 目標を開き、不足条件を特定します。覚醒条件なら対象の地域目標を進め、装備条件なら入場条件と現在の装備を比較してください。条件を満たしたらメイン目標へ戻ります。

<h2 id="skills-and-gear">目的を決めてスキルと装備を強化する</h2>

キャラクターレベル、アイテムレベル・装備スコア、戦闘力は別の成長指標です。素材を使う前に、対象コンテンツの必要条件を確認しましょう。まず進行を止めている条件を解決し、スキル、装備、その他の成長を整えます。

- クエスト報酬の有用な装備を使い、レア度だけでなく実際の能力を比較する。
- 新しい設定が開放されたら、よく使う攻撃、防御、支援スキルの説明を読む。
- ゲーム内のスキル連携機能が使える場合は、自分のスキルとキー設定に合わせる。他クラスの順序をそのままコピーしない。
- 明確な弱点や入場条件を解決するために強化素材を使う。序盤装備は後で交換することも考える。
- 強化の確認画面を読み、特殊な失敗ルールがある装備は特に注意する。

スキル選択は[ビルドとスキル](/builds)、短い攻撃の繰り返し設定は[マクロガイド](/macro-guide)を参照してください。

<h2 id="keep-materials">使い道がわかるまで素材を残す</h2>

用途がわかるまで、製作や育成の素材を残しましょう。売却、抽出、削除の前にアイテム説明と関連レシピを確認します。

すぐ使わない素材は倉庫へ移しましょう。一括保管や自動抽出の対象を確認し、クエストや納品に必要な装備を保護してください。

採集では、完成させたいレシピや強化に必要な素材を選びます。[採集ガイド](/gathering)で短いルートを作りましょう。

<h2 id="exploration-checklist">普段の移動に探索を組み込む</h2>

| 見つけたもの | 確認すること |
| --- | --- |
| 新しい移動地点 | 有効化済みで、帰りにも使えるか |
| 近くの羽根や探索収集物 | 現在の収集進捗と対応する報酬画面 |
| 封印ダンジョン | 必要レベル、目標、一度きりの成長報酬 |
| 拠点 | 完了状態と表示された装備素材 |
| ペットなど継続的な成長要素 | 普段のクエストと並行して開放できる内容 |

育成中は近くの収集物を拾い、残りは別の時間にまとめて回収しましょう。[マップガイド](/map)で必要な表示を有効にし、洞窟内の地点と地表の地点を見間違えないようにしてください。敵種族の地域では[PvP](/pvp)の危険があります。最初のプレイで急いで向かう必要はありません。

<h2 id="next-session">次回の目標とレベル45への移行</h2>

<GuideVisual id="workflow" />

Global開始時のレベル上限は**45**です。残りのメイン目標を終え、その段階で開くコンテンツを確認してから周回計画を作りましょう。

毎回のプレイは、メインストーリー、スキル強化、収集エリア、次のダンジョンから一つの目標を選んで始めます。入場回数や報酬を使う前に、残り回数とリセットのカウントを確認しましょう。

利用できる[公式コード](/code)と[Twitch Drops](/twitch-drops)は、対応するアカウントで受け取りましょう。終了前にバッグの空き、次のクエスト、次の活動の条件を確認すれば、次回も無理なく始められます。

<h2 id="community-resources">コミュニティ：Discord・Twitch・Reddit・Bahamut</h2>

知りたい内容に合った窓口を選びましょう。Globalの窓口は自分のサービス情報、台湾コミュニティは繁体字の交流やTWのプレイ情報に役立ちます。

| 窓口 | 用途 | 地域 |
| --- | --- | --- |
| [Global公式Discord](https://discord.gg/aion2official) | 告知、イベント、不具合報告 | Global |
| [AION2Official Twitch](https://www.twitch.tv/aion2official) | 公式配信と[Drops](/twitch-drops)情報 | Global |
| [r/Aion2](https://www.reddit.com/r/Aion2/) | プレイヤー質問、ビルド、ツール | Global・KR・TW。投稿の地域を確認 |
| [AION2 Bahamut掲示板](https://forum.gamer.com.tw/B.php?bsn=82913) | 繁体字のプレイヤー交流 | 台湾 |

アカウントの問題は[NCサポート](https://help.plaync.com/faq/aion2global)へ連絡してください。地域、サーバー、クライアント、エラー全文を添えると原因を特定しやすくなります。パスワードや認証コードは送らないでください。
