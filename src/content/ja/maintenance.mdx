<h2 id="check-current-status">自分のログインに関係する告知を確認する</h2>

1. 公式告知を開き、自分の地域に関係する最新情報を読みます。
2. 予定、進行中の障害、復旧報告のどれかを確認します。
3. 告知の日付とタイムゾーンを、現在の時刻と照合します。
4. 終了予定の更新や、その後の復旧メッセージを探します。
5. 該当する停止が告知されていなければ、以下のアカウント・クライアント確認に進みます。

終了予定は計画です。後から公開された復旧告知のほうが、そのイベントの終了を確認する根拠になります。復旧が案内されているのに、古い開始メッセージだけを最新状態として扱わないようにしましょう。

[公式Discord](https://discord.gg/aion2official)も告知の確認先です。韓国や台湾の投稿をGlobalに適用する前に、対象地域を読んでください。地域ごとに日程が異なる場合があります。

<h2 id="login-or-account-error">メンテナンスか、アカウント・クライアントの問題か</h2>

| 状況 | 次に確認すること |
| --- | --- |
| 現在の公式サービス停止がある | 告知の対象地域と最新の追記を確認する |
| 先行アクセス資格が認識されない | 再起動でNCの公開済み修正を適用し、資格を持つアカウントを確認する |
| 更新後も購入に問題がある | 購入修正告知と照合し、解決しなければサポートに相談する |
| 連携変更後にキャラクターが見つからない | 追加のアカウント連携をせず、公式連携ガイドに従う |
| ダウンロード済みなのに入れない | 先行アクセス資格と一般公開日程を確認する |

10月1日、NCは一部の先行アクセス認識・ゲーム内購入問題の修正を案内しました。**この更新にサービス停止は不要**で、再起動時に適用されます。同じ告知ではアカウント連携問題を引き続き調査中としています。[公式のアカウント・購入更新](https://aion2.plaync.com/en-us/board/notice/view?articleId=6abe2cf8a7ca1a15cf46bcbe)。

10月2日の[公式連携ガイド](https://aion2.plaync.com/en-us/board/notice/view?articleId=6abf40d99ed1202b9b8fb4fb)は、別のNCアカウントを追加連携すると既存の接続が解除され、キャラクターにアクセスできなくなる可能性を案内しています。キャラクターが見つからないことだけでメンテナンスとは判断できません。正しいアカウントの選び方は[Steam](/steam)と[Twitch Drops](/twitch-drops)を参照してください。

<h2 id="report-unresolved-errors">それでも接続できない場合</h2>

正確なエラー、地域、サーバー、SteamかPURPLEか、発生時刻とタイムゾーンを記録します。公開されたクライアント修正手順に従って一度再起動し、表示が変わるか確認してください。ランチャーとインストールの確認は[ダウンロードガイド](/download)にまとめています。

公式告知で説明できない場合は、その情報を[AION2サポート](https://help.plaync.com/faq/aion2global)に伝えてください。確認した資料には、サポートの回答時間、一律の障害復旧期限、すべての個人アカウント問題が解消したという保証はありません。
