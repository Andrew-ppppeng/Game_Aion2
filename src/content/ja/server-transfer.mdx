Globalのサーバー移転は**2026年10月14日開始予定**で、当初は無料・同じ種族内です。先行アクセスのキャラクターは、当初は先行アクセスサーバー同士でのみ移転できます。

<h2 id="confirmed-transfer-rules">Global移転条件</h2>

| 質問 | 移転条件 |
| --- | --- |
| 開始予定はいつ？ | 2026年10月14日 |
| 種族を変えられる？ | 同じ種族内での移転 |
| 先行アクセスから正式開始サーバーへすぐ移れる？ | 当初、先行アクセスのプレイヤーは先行サーバー同士に制限されます |
| 最初の料金は？ | 当初は無料 |
| 一緒にダンジョンへ行くために移転が必要？ | ダンジョンはサーバー間で利用可能 |

当初の無料移転にも同じ種族と先行アクセスの制限があります。条件に合う移転先を選びましょう。

<h2 id="choose-a-destination">開始前に移動先を決める</h2>

[サーバー一覧](/server)を使い、仲間と地域・種族・正確なサーバー名を合わせます。敵種族の対戦相手サーバーは、同じ種族の移転先ではありません。

フィールドで一緒に遊ぶなら同じサーバーを選びましょう。ダンジョンなどのインスタンスはサーバー間で遊べるため、そのためだけの移転は不要です。

<h2 id="prepare-your-information">必要な情報を整理する</h2>

1. 現在の地域、種族、正確なサーバー名を記録します。
2. 仲間と決めた移動先について、種族とアクセス区分も記録します。
3. 移動告知を開き直し、改訂や新しい利用条件の告知を探します。
4. 同じ拠点サーバーで遊ぶ、組織へ参加するなど、移動の目的を具体的に書きます。
5. 機能開始後、移動先選択と確認画面を読んでから確定します。

移転先の選択画面に表示されるサーバーを選びます。キャラクター一覧が予想と違う場合は、移転するキャラクターの[アカウントとクライアント](/steam)を確認してください。

<h2 id="unannounced-details">移転確定前の確認</h2>

確定前に移転先の条件、料金、名前重複、クールダウン、レギオン・メール・Market出品の扱いを確認します。自分の移転に適用されるGlobalの条件を読んでください。

<h2 id="check-at-opening">開始時に確認すること</h2>

開始時は[サービス告知](https://aion2.plaync.com/en-us/board/notice/list)と[メンテナンス情報](/maintenance)を確認し、対象キャラクターで移転が利用可能になってから進めます。

確認画面で移転先と最終料金を読んでから確定してください。移転後は移転先にログインし、目的のキャラクターを選んだことを確認します。
