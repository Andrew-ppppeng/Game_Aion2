<h2 id="official-downloads">Global版の公式ダウンロード先を選ぶ</h2>

GlobalのPC版は[Steam](https://store.steampowered.com/app/3393110/AION_2/)または[PURPLE](https://purple.plaync.com/download)から入手できます。公式サイトのDownloadメニューもこの2つにリンクしています。Steamでは、インストール前に本編の**AION 2、App 3393110**であることを確認してください。[NCのサービス開始告知](https://about.ncsoft.com/news/article/A2_update_20261001)は両プラットフォームと、2026年10月5日の一般向けサービス開始予定を案内しています。

10月2日時点のGlobalは、資格を持つプレイヤーが参加できる先行アクセス期間です。ダウンロード完了だけでは先行プレイ資格を取得できません。一般公開から無料で遊ぶ場合は、資格を購入せずにクライアントを準備できます。パッケージを選ぶ前に[Steamとサービス開始情報](/steam)、[課金システム](/monetization)を確認しましょう。

古いKR/TW向け解説には、モバイル版、電話番号認証、地域固有のフォルダーなどの手順が含まれます。GlobalのPC版では以下の手順を使い、別地域の設定を混ぜないようにしてください。

以下は2026年10月2日に確認した[Steamの公式製品データ](https://store.steampowered.com/api/appdetails?appids=3393110&cc=us&l=english)です。

| OS | Windows 10/11、64-bit | Windows 10/11、64-bit |
| CPU | Ryzen 5 2600 / Core i5-10500 | Ryzen 7 3700X / Core i7-11700 |
| メモリ | 8 GB RAM | 16 GB RAM |
| GPU | GTX 1050 Ti、4 GB | RTX 2070、8 GB |
| DirectX | 12 | 12 |
| 必要な空き容量 | 100 GB | 100 GB |
| 回線とドライブ | ブロードバンド、SSD推奨 | ブロードバンド、SSD推奨 |
| 公式のFHDプリセット注記 | Very Low | Low |

**100 GBは必要な空き容量であり、固定のダウンロードサイズではありません。** 圧縮された転送量や後日のパッチ容量は異なります。確定前にランチャーの現在の容量表示を確認してください。推奨環境の注記もFHD Lowであり、最高設定や特定のフレームレートを保証するものではありません。

**空き容量で止まる場合：** 別の空いているディスクではなく、実際に選んだドライブを確認します。現在のインストーラーの表示を読み、その条件を満たしてから再開してください。公開されている100 GBは必要な空き容量です。動画で転送量が小さく見えても、インストール時の確認条件は変わりません。

<h2 id="steam-installation">Steamでインストールする</h2>

1. 実際にプレイするSteamアカウントでログインします。
2. [AION 2の公式ストアページ](https://store.steampowered.com/app/3393110/AION_2/)を開き、アカウントで利用可能になった本編を追加・インストールします。
3. 十分な空き容量のあるドライブを選びます。SSDが推奨されます。ダウンロードと更新が完了するまで待ちましょう。
4. ライブラリから本編を起動し、そのクライアントに表示されるアカウント案内に従います。
5. キャラクター作成前に、友人と[地域・種族・サーバー](/server)を決めておきます。

以前のテストに参加した場合は、ライブラリの項目がテスト用ではなく本編か確認してください。テスト版を導入しただけで、現行クライアントやテストキャラクターの引き継ぎが保証されるわけではありません。コミュニティに保存された[Launch Scale Test FAQ](https://discord.com/channels/1113589630122606594/1113589937682526321/1549515406614601739)では、Steam本編の導入とテスト版を区別しています。

**Steamの具体例：本体はインストール済みだが、ファイル不足と表示される。** **AION 2、App 3393110**を開いたことを確認し、**Properties → Installed Files → Verify integrity of game files**を使います。処理完了を待ってから再試行してください。次に参加資格やメンテナンスの表示が出たら、その原因への対処に移ります。ファイル確認によって先行プレイの資格が付いたり、停止中のサービスが開いたりはしません。

<h2 id="purple-installation">PURPLEでインストールする</h2>

1. [PURPLEの公式ダウンロードページ](https://purple.plaync.com/download)からランチャーを入手します。
2. インストールして起動し、プレイするアカウントでログインします。
3. AION2のGlobalサービスを選び、保存先を指定してランチャーに表示されるダウンロード・更新を完了します。
4. 更新後にPURPLEからゲームを起動します。再インストールの前に、資格やメンテナンスの表示を確認しましょう。

**インドネシア、マレーシア、フィリピン、シンガポール、タイ**でAION2が表示されない場合、NCはPURPLEのランチャー地域を**Global**にし、一覧を確認して必要ならPURPLEを再起動する方法を案内しています。これは[公式の地域設定告知](https://aion2.plaync.com/en-us/board/notice/view?articleId=6abd3200a279104f7d9d5eeb)に記載された国のランチャー設定であり、アカウントの国を変更する手順ではありません。

**公式対象国でのPURPLEの具体例：** **シンガポール**のプレイヤーにAION 2が見えない場合、引用した公式告知は**ランチャーの地域をGlobalにする**、ゲーム一覧を見る、必要ならPURPLEを再起動するよう案内しています。対象国に公開されたランチャーの対処として適用してください。アカウントの国変更やKR/TWサービス選択とは別の操作です。

<h2 id="launch-troubleshooting">ダウンロード後に起動できない場合</h2>

| 状況 | 最初に確認すること | 次の操作 |
| --- | --- | --- |
| 資格・利用権のエラー | 現在の先行アクセス資格とログイン中のアカウント | [公式のアカウント修正情報](https://aion2.plaync.com/en-us/board/notice/view?articleId=6abe2cf8a7ca1a15cf46bcbe)を確認し、クライアントを再起動・更新する |
| PURPLEにゲームがない | ランチャーのGlobal設定と上記の国別告知 | 公開された設定を適用後、PURPLEを再起動する |
| サービスが利用できない | 最新の[メンテナンス告知](/maintenance) | 何度も再インストールせず、告知の終了を待つ |
| Steamが破損・欠落ファイルを報告 | ライブラリの本編項目 | ライブラリ→プロパティ→インストール済みファイル→ゲームファイルの整合性を確認する |
| インストールが終わらない | 選択したドライブの空き容量 | 現在の容量エラーに従う。動画の転送量を必要容量と同一視しない |

ファイルの確認手順は[Steamサポート](https://help.steampowered.com/en/faqs/view/0C48-FCBD-DA71-93EB)に記載されています。改善しなければ、正確なエラー、ランチャー、地域、発生時刻を記録して[AION2公式サポート](https://help.plaync.com/faq/aion2global)に相談してください。TW版の設定ファイルの場所は、Globalの確認済み修正方法ではありません。
