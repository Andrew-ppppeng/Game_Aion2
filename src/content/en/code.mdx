<h2 id="redeem-coupon">How to redeem the coupon</h2>

Open **Settings → Miscellaneous → Account → Enter Coupon**.

1. Launch the Global client and sign in with the account you actually play.
2. Open Settings, then Miscellaneous and Account.
3. Select Enter Coupon.
4. Copy the coupon from the card above. Check for an extra space before or after it.
5. Select Confirm and read the client's result before trying again.

Advanced Access requires an eligible Founder's Pack. If you cannot reach the coupon menu, check the account that owns access and the [Steam guide](/steam). Public Global access is scheduled for October 5 at 13:00 UTC. The coupon has its own expiry on the card above.

<h2 id="redemption-problems">If the coupon is rejected</h2>

Use the error shown by the client to narrow the problem before repeating the same action.

| Check | What to do |
| --- | --- |
| Correct region | Use the Global coupon with your Global account. |
| Correct text | Compare the entire coupon with the card, including its final characters; remove copied spaces. |
| Expiry | Check the coupon card’s deadline and time zone. |
| Previous use | Check whether this account already redeemed it; the allowance is shared across servers. |
| Login or service problem | Read the latest [maintenance information](/maintenance) before treating a failed login as an invalid coupon. |

If redemption still fails, contact [AION 2 support](https://help.plaync.com/faq/aion2global) with the error, region, login method and attempt time.
