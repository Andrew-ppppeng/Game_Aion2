<h2 id="official-downloads">Choose an official Global download</h2>

Download AION 2 Global for PC through [Steam](https://store.steampowered.com/app/3393110/AION_2/) or [PURPLE](https://purple.plaync.com/download). On Steam, select **AION 2, App 3393110**.

Advanced Access requires an eligible Founder's Pack. The base game is free-to-play at public launch on October 5, 2026, so you can prepare the client without buying early access. See [Steam and launch information](/steam) and [monetization](/monetization) before choosing a package.

<h2 id="pc-requirements">Check your PC and storage first</h2>

**Global PC requirements:** the officially supported Global client is for Windows PC. Use this table for that client; KR/TW mobile specifications apply to separate regional clients. See [platform support](/steam#platform-and-controller-support) before choosing a device.

| Component | Minimum | Recommended |
| --- | --- | --- |
| Operating system | Windows 10/11, 64-bit | Windows 10/11, 64-bit |
| Processor | Ryzen 5 2600 / Core i5-10500 | Ryzen 7 3700X / Core i7-11700 |
| Memory | 8 GB RAM | 16 GB RAM |
| Graphics | GTX 1050 Ti, 4 GB | RTX 2070, 8 GB |
| DirectX | 12 | 12 |
| Available storage | 100 GB | 100 GB |
| Connection and drive | Broadband; SSD recommended | Broadband; SSD recommended |
| FHD preset | Very Low | Low |

Reserve **100 GB of available disk space** and check the launcher's estimate before installing. The download and later patches can differ in size. The minimum and recommended FHD presets are Very Low and Low respectively.

**If installation stops for space:** free room on the selected installation drive, then resume once it meets the installer's requirement.

<h2 id="check-your-specs">Check your own PC specs</h2>

1. Press **Windows + R**, enter `dxdiag`, and open the DirectX Diagnostic Tool.
2. On **System**, check the operating system, processor, memory and DirectX version. Compare each with the table above.
3. On **Display**, check the graphics adapter's name. If your PC has several adapters, check the other Display or Render tabs too.
4. Check free space on the drive you will select in Steam or PURPLE. The storage requirement is available disk space, not an exact download size.

Start with **Very Low at FHD** on the listed minimum hardware or **Low at FHD** on the recommended hardware. These presets do not promise a fixed frame rate.

**Can I install it on a phone?** These instructions install Global's Windows PC client. Do not use a KR/TW mobile download or phone requirements as a substitute for the Global installer.

<h2 id="steam-installation">Install through Steam</h2>

**Steam account:** you do not need to link a PURPLE account to play through Steam. Link accounts only if you want the same character and progress in both launchers; both use the same Global content and servers.

1. Sign in to the Steam account you actually intend to play on.
2. Open the [official AION 2 store page](https://store.steampowered.com/app/3393110/AION_2/) and add/install the main game when available to your account.
3. Choose a drive with sufficient free space, preferably an SSD. Let Steam finish downloading and applying updates.
4. Launch the main game from your Library and follow the account prompts presented by that client.
5. Before creating a character, agree on your [region, faction and server](/server) with friends.

After a test, install the main **AION 2, App 3393110** Library entry for Global play. The Playtest is a separate application.

**If Steam reports missing or damaged files:** open AION 2 in your Library, then select **Properties → Installed Files → Verify integrity of game files**. Let verification finish before relaunching.

<h2 id="purple-installation">Install through PURPLE</h2>

1. Get the launcher from the [official PURPLE download page](https://purple.plaync.com/download).
2. Install and open PURPLE, then sign in with your intended playing account.
3. Select the Global AION 2 service, choose its installation location and complete the download/update shown by the launcher.
4. Start the game from PURPLE after updating. Read any access or maintenance message before reinstalling anything.

If AION 2 is missing from PURPLE in **Indonesia, Malaysia, the Philippines, Singapore or Thailand**, set the **launcher region to Global**, check the game list and restart PURPLE if needed. Keep your account country unchanged.

<h2 id="taiwan-client">Install the separate Taiwan client</h2>

**TW/KR progress does not transfer to Global.** Choose the service you want before creating a character.

**TW:** use the [official Taiwan download page](https://tw.ncsoft.com/aion2/download/index). It installs a separate regional service; the Global Steam app is not a Taiwan-server installer.

1. Download and install **PurpleInstaller** from the Taiwan page.
2. Start PURPLE and choose **AION2** in **STORE**.
3. In the AION2 game lobby, select the game-install button and finish the download and updates.

**TW account:** sign in with your own account and complete the Taiwan service's account checks. Registration details must match your identity documents and remain verifiable. Installation alone does not confirm regional eligibility; contact [Taiwan AION 2 support](https://help.plaync.com/faq/aion2_tw) if account verification or regional access blocks you.

<h2 id="launch-troubleshooting">If the download finishes but the game will not start</h2>

| What you see | First check | Next action |
| --- | --- | --- |
| Access or eligibility message | Advanced Access entitlement and signed-in account | Restart and update the client; check that this account owns access |
| Game missing from PURPLE | Launcher region and the country list above | Set the launcher to Global and restart PURPLE |
| Service unavailable | The latest [maintenance notice](/maintenance) | Wait for the announced completion instead of repeatedly reinstalling |
| Steam reports damaged or missing files | Main-game Library entry | Use Library → Properties → Installed Files → Verify integrity of game files |
| Installation cannot finish | Free space on the selected drive | Meet the installer’s storage requirement and resume |

If the problem persists, record the error, launcher, region and time for [AION 2 support](https://help.plaync.com/faq/aion2global).
