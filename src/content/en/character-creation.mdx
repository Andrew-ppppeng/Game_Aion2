<h2 id="creation-decisions">Choose your region, faction and class first</h2>

Before spending time on sliders, agree on a **region, faction and server** with the people you want to play alongside. AION 2 Global offers Elyos and Asmodians and eight classes in the [official game introduction](https://aion2.plaync.com/en-us/about/index). See [all classes](/classes) for combat roles and [servers](/server) for current server choices.

| Decision | Check before confirming |
| --- | --- |
| Region | The region your group will actually play in, rather than the language of a tutorial |
| Faction | Elyos or Asmodians; coordinate the choice with friends |
| Server | Exact server name and region, and whether it currently accepts creation |
| Class | Preferred combat role, range and support responsibilities |
| Appearance | A starting template you can refine and inspect from several angles |

NC recommends considering a recommended server when existing servers have queues. Its [server-transfer notice](https://aion2.plaync.com/en-us/board/notice/view?articleId=6abd2d50a279104f7d9d5ee2) announces transfers starting October 14 within the same faction; the initial EA-to-EA restriction means a future transfer is not a promise that every server choice can be repaired freely.

<h2 id="appearance-workflow">Build the appearance from broad shapes to details</h2>

<GuideVisual id="workflow" />

The official [Global introduction](https://aion2.plaync.com/en-us/about/index) advertises over 200 customization options. That describes editing variety, not save slots. A practical approach is to establish the overall silhouette first, then refine the face and styling.

1. Select the starting template and compare the available base appearances. Begin near your target instead of fighting every slider.
2. Set broad face and body proportions while checking both front and side views.
3. Refine eyes, brows, nose and mouth. Change one feature at a time so you can see which adjustment caused a result.
4. Choose hair shape and colors, then inspect how it frames the face.
5. Add makeup, tattoos, scars or other details after the main proportions work.
6. Preview the full character under different lighting and clothing before confirming.

This editing order is a recommendation. The control examples below follow [Wiggles' character-customization walkthrough](https://www.youtube.com/watch?v=i82EC5vzq8I), a player demonstration rather than a guarantee that every Global panel has identical labels.

**A reproducible editing test:** keep the starting template, hairstyle and lighting fixed. Inspect the nose and chin from the front and profile, then change only one relevant slider. If a numerical value is shown, note it before adjusting. Rotate again before moving a second slider; restore the noted value if the profile became worse. This makes the effect of one edit visible instead of masking it with several simultaneous changes.

<h2 id="face-hair-details">Check the face, hair and detail panels</h2>

| Area | Useful checks | Common mistake |
| --- | --- | --- |
| Eyes and brows | Shape, spacing, iris/color choices and any asymmetry controls | Judging only from a close frontal view |
| Nose and mouth | Profile, projection and balance with the jaw | Making a small frontal adjustment that changes the side silhouette |
| Hair | Primary/secondary colors, shine and the face outline | Matching a screenshot color under only one lighting preset |
| Makeup and markings | Placement and visibility under the chosen hair | Adding strong details before the face is settled |
| Body | Overall template, proportions and layered adjustment controls | Assessing the face without checking the full-body result |

The cited walkthrough demonstrates separate eye, brow, nose, mouth, hair, makeup and body editing. Use it for visual guidance when a control's effect is unclear. Do not confuse a creator's screenshot tile position with a permanent official option ID: the layout can differ with resolution or client version.

<h2 id="preview-checklist">Preview before you finalize</h2>

- Rotate to front, profile and three-quarter views. Check the nose, chin, ears and hair from each.
- Compare close-up and full-body views. A pleasing portrait may have different proportions at gameplay distance.
- Try more than one lighting setup and an outfit preview where the editor offers them.
- Recheck hair and makeup after changing the face: they may now hide or emphasize a different feature.
- Verify the character's class, faction and server selection before the final creation action.
- Follow the name validation shown by your current creation screen. We have not independently verified Global's exact name-length, character-slot or deletion-wait limits.

If a server prevents creation, check the current [official announcements](https://aion2.plaync.com/en-us/board/notice/list) and server screen. Do not rely on a fixed unlock time quoted in an older community discussion.

**When the final action fails:** read the message before changing unrelated settings. A name-validation message should be resolved using that screen's allowed format; it does not prove a particular universal length or deletion timer. A creation restriction should be checked against the selected server and current notice. If the appearance alone looks wrong, return to its preview and compare the same camera and light before starting the character over.

<h2 id="shared-presets">Use shared styles and plan later appearance changes</h2>

Browse the [official Global Style Shop](https://aion2.plaync.com/en-us/styleshop/popular) for inspiration, selecting the relevant region before comparing styles. Our [presets guide](/presets) covers the player-reported download → character selection → Manage Appearance workflow for an existing character.

**Initial-creation importing is not verified here.** The available source does not establish that a downloaded website appearance can always be loaded before a character exists. Use the creation screen's offered controls and keep any creator-provided manual settings for later comparison.

An appearance download also does not establish that a later in-game application is free. Inspect the current confirmation screen for cost or voucher eligibility before changing an existing character. For the first session, finish creation, check controls and continue with the [beginner guide](/guide) rather than assuming an old KR/TW appearance rule applies to Global.
