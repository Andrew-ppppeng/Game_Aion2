<h2 id="find-presets">Find character presets in the official Style Shop</h2>

Browse shared appearances in the [official AION 2 Style Shop](https://aion2.plaync.com/en-us/styleshop/popular). Select your region, choose a period and sort by **Most Downloaded** or **Most Liked**. Compare the face, hair and full-body previews before choosing a look.

You can use a shared Style Shop appearance or recreate a look with manually documented sliders. Style Shop sends a download to your selected character; manual presets require you to enter the settings in the editor.

Save the listing of a style you like so you can find it again. The **Download** action sends it to a character; browsing previews is free.

<h2 id="download-apply">Download and apply a shared appearance</h2>

<GuideVisual id="workflow" />

1. Sign in to the official website using the platform identity you actually play on, such as your Steam or PURPLE login.
2. Open your profile, choose **Change Character**, and select the intended recipient.
3. Open **Style Shop**, select an appearance, click **Download**, and choose a slot offered by the current website.
4. Open the game on that same character and enter **Customizations → Manage Appearance**.
5. Use **Refresh** if the download is not displayed immediately, then select the downloaded appearance to preview it.
6. Inspect the confirmation screen before applying. Confirm its current Quna cost or eligible appearance-change voucher, and proceed only if you accept the displayed terms.

**Downloading and applying are separate actions.** Preview the downloaded look and check the displayed Quna cost or eligible voucher before confirming an appearance change. See [monetization](/monetization) for currency planning.

<h2 id="upload-style">Share your own style</h2>

1. Open **Snapshot** on the character whose appearance you want to share.
2. Take a clear main preview and additional views of the face, hair and body, using consistent lighting.
3. Locate the saved screenshots. For Steam, check `AppData\Local\AION2\Saved_Steam\Screenshots`; PURPLE uses its own screenshot folder.
4. Select **the same character** on the website.
5. Open **My Style → Register My Style**, upload the requested previews and complete the registration form.

Follow the Style Shop's registration requirements and [content rules](https://aion2.plaync.com/en-us/board/rules/view?articleId=6aac4c8fab04307987fe2b4c). Share your own work or obtain permission before distributing someone else's style.

<h2 id="manual-sliders">Use a manual slider preset</h2>

For a manual preset, keep the creator's slider screenshots or written values beside the editor. Match the starting template before entering detailed settings.

- Match the template, face and hair options before entering fine adjustments.
- Work through face shape, eyes, nose, mouth, hair, makeup and body in order. A different starting template can change the result.
- Use the shown colors and values where available. A guessed position on a two-dimensional slider is an approximation.
- Compare front, side and three-quarter views under multiple lighting presets before confirming.

Use the [character creation checklist](/character-creation) to review proportions, camera angles and lighting before confirming.

<h2 id="preset-troubleshooting">Troubleshoot missing or incompatible presets</h2>

| Problem | What to check |
| --- | --- |
| Download is missing in game | Website login identity, selected character, selected region, then Manage Appearance → Refresh |
| Website shows the wrong character | Sign out and select the actual playing platform; do not assume matching email addresses mean the same game account |
| Preview looks different | Starting template, camera angle, light, hair color and outfit; compare several views |
| You have a KR/TW appearance link | Find a Global listing or use the creator’s manual slider settings |
| You want a preset for a new character | Use the presets and editing controls offered on the creation screen |

Keep the creator's page link and any manual settings you entered so you can revisit them. For account problems, follow [official support](https://help.plaync.com/faq/aion2global) rather than repeatedly applying a paid change to test whether synchronization worked.

**If Refresh still shows nothing:** compare the website's selected character and server with the character currently open in game, then confirm the platform identity and region. Return to the website to inspect the intended download slot before attempting another application. Keep the appearance link and record the selected recipient and time for support. A missing preview is not a reason to confirm a second paid appearance change.
