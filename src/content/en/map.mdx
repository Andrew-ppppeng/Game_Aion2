<h2 id="choose-map">Choose an interactive map for your task</h2>

Use a filtered map for resource routes and a map with height information when a marker appears above or below you. AION 2's terrain includes elevated platforms and caves, so plan the approach as well as the destination.

| Tool | Best use | Useful controls |
| --- | --- | --- |
| [Aion2T Interactive Map](https://aion2t.com/map) | Resource and collectible routes | Zone selector, search and category filters |
| [Aion2Maps](https://www.aion2maps.com) | Heights, cave access and collection progress | Voxel terrain view and progress sync code |
| [Aion2Hub Maps](https://aion2hub.com/maps) | Alternative resource and zone map | Filters and route planning |

The old `aion2.app/map` address redirects to Aion2T. Choose your service region in the tool and compare unclear locations with the in-game map.

<h2 id="faction-zones">Select the right faction and zone</h2>

The Elyos map is **Verteron**; the Asmodian map is **Altgard**. Dawn Legion Base and Cantas Valley are Elyos landmarks, while Safe Haven and Moslan Forest are Asmodian landmarks.

1. Check your character's faction and the zone name shown in game.
2. Choose the matching zone in the external map's selector.
3. Disable unrelated categories, then enable the resource or collectible you need.
4. Confirm a nearby landmark or teleport point before following markers.
5. If a route crosses into another faction's territory, assess the [PvP or rift conditions](/spacetime-rift) before treating it as a routine gathering route.

<h2 id="ingame-filters">Show exploration content on the in-game map</h2>

Open the large map and its filter settings to show exploration content. Look for **Filter Settings → Content** or the equivalent labels in your client language. Hidden layers can explain why a collectible appears on an external map but not in game.

- Open the large map and inspect its filter panel before assuming a collectible is missing.
- Enable the relevant content layer, then zoom in so nearby icons are distinguishable.
- Compare the in-game marker with the community map's marker and a visible landmark.
- Use your client's collected/uncollected display where available to avoid repeating a completed stop.

Collect nearby exploration items while leveling. For a dedicated session, clear one area at a time and track completion in your collection screen.

<h2 id="resource-route">Build a practical gathering or collection route</h2>

<GuideVisual id="workflow" />

1. Choose one goal: a crafting material, an exploration collectible or an unfinished dungeon/teleport point.
2. Filter for that goal and pick a compact cluster near a known starting landmark.
3. Order the stops around terrain access, not just straight-line distance. Check ramps, cave mouths and flight access before committing to a loop.
4. Add a manageable set of stops using the map’s available marker capacity.
5. Run the loop once, noting failed gathers, inaccessible points and missing spawns. Adjust the route before repeating it.

For resource runs, record material yield and elapsed time so you can decide whether the loop is useful. Map markers indicate possible node locations. Skip an absent node and continue the route. See [gathering](/gathering) for choosing materials and checking skill requirements.

**Filter example for Elyos:** open [Aion2T](https://aion2t.com/map), select **Global → Verteron**, click **Hide All**, enable **Herbs** and turn off **Targena** to leave only **Aria**. For an Asmodian character, select **Altgard** before choosing a material. The map marks possible node locations; check the node's gathering requirement when you arrive.

<h2 id="map-troubleshooting">Fix missing markers and protect progress</h2>

| Problem | What to try |
| --- | --- |
| Marker is directly on you, but nothing is visible | Check height, caves and adjacent access paths; use the voxel map to inspect vertical position |
| No resources appear | Confirm the selected zone, category and search filter; compare with the game's displayed node requirements |
| A chest or node is absent | Treat the point as a possible spawn location; move on rather than assuming an exact respawn timer |
| The same collectible keeps appearing in your route | Mark completion in the tool and compare against your in-game progress |
| Progress differs between devices | Use the tool's documented sync/export function where available and preserve its recovery information before clearing browser data |

Save the Aion2Maps progress sync code before switching devices or clearing browser data. Keep a separate note of completed zones during long collection runs. Report incorrect coordinates with the zone name and game version.
