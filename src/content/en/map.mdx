<h2 id="choose-map">Choose an interactive map for your task</h2>

Use a filtered map for resource routes and a map with height information when a marker appears above or below you. AION 2's world is built around vertical exploration, so a point on a flat map is often only the first clue. The following are community tools, not NC-operated live server maps.

| Tool | Best starting use | Evidence and limitation |
| --- | --- | --- |
| [Aion2T Interactive Map](https://aion2t.com/map) | Select a zone, search and narrow the visible markers | Its map selector, search and Filters interface were checked; individual points are not guaranteed current for every Global patch |
| [Aion2Maps](https://www.aion2maps.com) | Find the correct height or a cave entrance; track collection progress | The [creator's introduction](https://www.reddit.com/r/Aion2/comments/1wtsfhn/3d_interactive_voxel_maps_for_aion_2_generated/) describes Global client coordinates, gathering nodes and a progress sync code; those are author-reported features |
| [Aion2Hub Maps](https://aion2hub.com/maps) | An alternative resource/zone map | A [player demonstration](https://www.youtube.com/watch?v=k7Ud_YkU_SI) shows filters and route planning; verify the current version before following old routes |

The old `aion2.app/map` entry leads to Aion2T. Treat them as one tool rather than two independently verified datasets. Start with one map, keep its region/version in mind and compare confusing locations against the in-game map.

<h2 id="faction-zones">Select the right faction and zone</h2>

The Global [official game introduction](https://aion2.plaync.com/en-us/about/index) presents Elyos locations in **Verteron** and Asmodian locations in **Altgard**. Their landmarks differ: Dawn Legion Base and Cantas Valley are Elyos examples; Safe Haven and Moslan Forest are Asmodian examples. Use these as orientation landmarks, not a mandatory travel itinerary.

1. Check your character's faction and the zone name shown in game.
2. Choose the matching zone in the external map's selector.
3. Disable unrelated categories, then enable the resource or collectible you need.
4. Confirm a nearby landmark or teleport point before following markers.
5. If a route crosses into another faction's territory, assess the [PvP or rift conditions](/spacetime-rift) before treating it as a routine gathering route.

A zone with the right shape but the wrong faction or regional dataset can send you to unreachable points. Do not copy a later KR/TW expansion route into your Global starting area.

<h2 id="ingame-filters">Show exploration content on the in-game map</h2>

A [player map-filter walkthrough](https://www.youtube.com/watch?v=rlYdxp4XTFM) demonstrates opening the large map, selecting **Filter Settings**, and enabling **Content** to show exploration markers. It also explains why an external feather map can show points that are hidden by the in-game filter. This is player guidance from an earlier client; current Global labels may differ.

- Open the large map and inspect its filter panel before assuming a collectible is missing.
- Enable the relevant content layer, then zoom in so nearby icons are distinguishable.
- Compare the in-game marker with the community map's marker and a visible landmark.
- Use your client's collected/uncollected display where available to avoid repeating a completed stop.

For leveling, take nearby exploration stops when convenient. For a dedicated collection session, clear one area at a time and record progress. Reward totals and thresholds should come from your current character UI rather than an old video.

<h2 id="resource-route">Build a practical gathering or collection route</h2>

<GuideVisual id="workflow" />

1. Choose one goal: a crafting material, an exploration collectible or an unfinished dungeon/teleport point.
2. Filter for that goal and pick a compact cluster near a known starting landmark.
3. Order the stops around terrain access, not just straight-line distance. Check ramps, cave mouths and flight access before committing to a loop.
4. Transfer a manageable set of stops to the game's available markers. Do not rely on the marker limit mentioned in an older video.
5. Run the loop once, noting failed gathers, inaccessible points and missing spawns. Adjust the route before repeating it.

For resource runs, record material yield and elapsed time so you can decide whether the loop is useful. A map shows where a node can occur; it does not establish that the node is currently available. See [gathering](/gathering) for choosing materials and checking skill requirements.

**Try this exact filter exercise:** open [Aion2T](https://aion2t.com/map), confirm its Global mode and choose **Verteron**. Click **Hide All**, enable **Herbs**, then turn off **Targena** so that only **Aria** remains selected. We tested those controls on October 3. Use the resulting cluster to understand the tool; it does not establish your character's gathering requirement or the location of a currently spawned node. For an Asmodian character, choose **Altgard** first instead of following this Elyos-zone view.

<h2 id="map-troubleshooting">Fix missing markers and protect progress</h2>

| Problem | What to try |
| --- | --- |
| Marker is directly on you, but nothing is visible | Check height, caves and adjacent access paths; use the voxel map to inspect vertical position |
| No resources appear | Confirm the selected zone, category and search filter; compare with the game's displayed node requirements |
| A chest or node is absent | Treat the point as a possible spawn location; move on rather than assuming an exact respawn timer |
| The same collectible keeps appearing in your route | Mark completion in the tool and compare against your in-game progress |
| Progress differs between devices | Use the tool's documented sync/export function where available and preserve its recovery information before clearing browser data |

Aion2Maps' creator reports a sync code for progress sharing; this wiki has not tested every recovery scenario. Keep an independent note of completed zones for long collection sessions, and report incorrect coordinates to the tool author with your zone and game version.
