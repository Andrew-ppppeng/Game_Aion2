# AION 2 数据库与工具平台

决策日期：2026-10-04。用户已授权实施。面向 Global，英语优先，同时保留 ja/es/de。首版无登录，浏览器保存，支持备份和装备计划分享。客户端解析仅进入 TODO。地图缺少官方数据时先发布数据库。

## 已实现的基础功能（全量数据库未完成）

- `/database`：保留攻略 URL、原有标题与正文，加入装备目录、名称/ID搜索、地区/类别/品质/职业/等级过滤及排序。目录显示真实收录数量，不宣称全量。现有官方快照收录 22 件。
- `/database/items/[id]`：四语言详情、实际字段、随机属性池、强化模板查询、收藏与目标；只发布已验证 ID。原有地区验证继续生效，Asia 没有有效模板时拒绝展示其他地区数值。
- 全站搜索：攻略、八职业与装备，本地索引；角色查询保持明确提交后远程请求。快捷键 Ctrl/Cmd+K。
- `/tools/compare`：两个模板和强化等级，按实际同 ID/同单位属性比较；随机属性不参与固定差值。取消过期请求。
- `/workspace`：收藏、最近浏览、升级目标、用户清单、多套具名装备计划、备份导入/导出、Unicode 分享链接。分享仅包含装备计划；个人数据不放 URL。个人页 noindex。
- `/tools`：实际可用工具入口；`/tools/budget`、`/tools/calendar`复用现有材料预算与活动日历，保留原攻略锚点。
- 角色页：手动保存历史快照，同角色/同地区比较；成长面板按实际 row/col 展示可点击节点与属性。不推测连接、最优路线或解锁成本。
- 现有缓存、并发锁、限流和 ApiResult 继续用于实时 API；节点请求先验证面板属于当前角色。
- 发布装备与工具页加入多语言 sitemap。查询参数结果与个人计划不索引。保留旧存储键与原始 research。

## 数据门槛与后续顺序

2026-10-04 用户指出 22 件样本远低于参考站的数千件物品。后续第一优先级是完成官方目录发现、可恢复的批量采集、地区/版本验证和覆盖率核验，再扩展工具。固定样本名单是当前实现的范围限制，不是上游 API 限制；不能把全量数据采集缺口仅列为可选后续功能。

| 模块 | 当前状态 | 启用条件 |
| --- | --- | --- |
| Global 全量数据库 | 部分目录可用 | 官方完整 ID 清单/分页契约；当前静态收录不可宣称全量 |
| 交互地图 | 等待数据，不展示空功能 | 官方底图、坐标系、地区、实体类型及稳定 ID；地图与详情互链；完成点本地保存 |
| 技能数据库/配点模拟 | 当前仅角色技能配置 | 独立技能详情、级别数值、冷却/消耗、配点约束 |
| 任务/NPC/怪物/掉落关系 | 等待数据 | 官方关联 ID、任务前置、奖励、掉落条件；概率缺失不填 |
| 配方与材料链 | 手动预算可用 | 配方 ID、投入产出、制作条件与费用；无配方不得自动生成链 |
| 强化收益/概率模拟 | 属性模板比较可用 | 官方成本、成功率与失败规则；不能把模板增量当实际成功率 |
| 市场价格/历史/收益 | 手动价格预算可用 | 官方地区服价格流、更新时间及保留历史的许可 |
| 登录、云同步与社区贡献 | 后续 | 身份验证、数据迁移/冲突方案、贡献审核 |
| 客户端解析 | TODO，未执行 | 单独确定授权、版本、资源格式、实体和坐标映射；不得混进官方 API 来源 |

实施原则：每次新增数据先归档原始响应，校验地区、语言、实体 ID 与数值结构，再发布快照。禁止跨地区兜底、批量猜测 ID 或把 TW 词典当 Global 全量接口。
