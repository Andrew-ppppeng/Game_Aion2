## 验收命令

构建当前源码后，依次运行 `test:content`、`test:data`、`check`、`test:smoke`、`test:browser`、`test:review`、`test:navigation`、`test:tools`、`test:share`、`test:site-info`、`test:analytics`。性能检查单独执行，避免其他浏览器任务争用 CPU：`test:performance`。

复用本轮的隔离预览时设置以下环境变量，避免误读原有 3000 端口页面或旧构建 ID：

```powershell
$env:QA_BASE_URL = 'http://127.0.0.1:3002'
$env:NEXT_PUBLIC_SITE_URL = $env:QA_BASE_URL
$env:QA_BUILD_DIR = '.next-review-final'
```

性能脚本覆盖首页、guide、classes、map、builds 和角色工具，各三次冷缓存；默认预算 LCP 2500ms、CLS 0.1、总传输 700KB、脚本 220KB、实验室交互 200ms，超限失败退出。实验室交互不是用户访问的真实 INP。
